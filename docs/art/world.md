# 世界観・美術設定

本書は [作品思想](../../README.md)、[ストーリーバイブル](../story-bible.md)、[人物の外見設定](../character-design.md)、[台本目次](../../script/README.md)、[執筆計画](../writing-plan.md) を美術へ具体化する。事件・出演・経過月は各部台本を、顔・体格・衣装は人物設定を正とする。街の素材、配色、暦月の対応は今回の美術補足であり、原作の確定事実と区別する。

![十二時二十分の青葉店と主要10人のカラーキービジュアル](../../art/key-visual/01-key-visual-color.png)

キービジュアルは十八か月の関係を集めた宣伝用の集合構図。全員が同じ日に青葉店にいたという本編の事件にはしない。遥のエプロンは手伝い中の姿であり、昼食客として来るENG-01では外す。タイトル「こはるキッチンの開発日誌」はこの画像に指定された文字として入れる。

## 時代と街

現代日本の地方都市。都市名・実在の駅名・西暦は固定しない。低層の商店と住宅、駅へ向かう徒歩・自転車の流れ、小さな事業所が同じ生活圏にある。スマートフォン、ノートPC、紙、電話が同じ机で使われる。未来的な投影画面や巨大な開発施設を足さない。

青葉店は商店街の店。ガラス入口、布ののれん、木目の受渡しカウンター、金属棚、丸い壁時計、紙台帳が場面の目印になる。既存ページの棚とカウンターの関係を保ち、人物の視線が「客の手元→現物→記録」へ移るように見せる。方角・家具配置の美術上の共通基準は [舞台設定](locations.md#青葉店全体の間取り)にまとめる。キービジュアルや季節ボードの建物配置・寸法は、間取りを更新する根拠にしない。

駅前店は同じチェーンの既存店。駅への短い滞在時間、初めて来る客、名字だけでは探せない受取りを背景の行列・荷物・歩く方向で示す。立花は青葉店と異なる条件を知る店長。看板、制服、容器の共通性と、列・案内・受取口の違いを併置する。

全8店舗、中央調理拠点1、従業員約100人という規模を保持する。青葉店と駅前店の試行から全店へ広がる物語であり、駅前店を新規9店舗目として描かない。中央調理と各店の仕上げの細かな分担は台本にある範囲で描く。

## こはるキッチンのブランド

屋号は「こはるキッチン」。支店名を一段下に「青葉店」「駅前店」と置く。「青葉」だけを別ブランドにしない。既存ページの小さな葉の意匠を二枚葉の簡潔な印へ整え、濃い面では白抜き、白地では黒一色で使う。文字は柔らかく読みやすい手書き風を基本とし、細い装飾線や新しいマスコットは加えない。

カラーの補足色は濃紺、生成り、木の淡い茶、葉の落ち着いた緑。制服の濃紺と遥の生成りは既存人物設定による。ロゴの緑や内装の茶は今回の美術補足。漫画では [画風ルール](style-guide.md) の濃淡へ置き換え、赤いペン・青いテープも着色しない。

店は毎日使われ、手入れされている。角の擦れた台帳、畳んだ袋、補充待ちの容器、作業台に置いた伝票で生活感を出す。食品に汚れを付けたり、通路を荷物で塞いだりして忙しさを表現しない。客席や打合せの席は小規模に扱い、弁当店を大きなレストランへ変えない。

## 灯台ソフトの空気

従業員24人の会社。主な兼務チームは遥・藤堂・水野・森・相原の5人。蓮は別案件から水野が調整して招く助っ人であり、常勤6人目の固定席を作らない。

執務室は普通の机、事務椅子、共有の打合せ机、資料棚、ホワイトボード。机上の図、紙札、手帳、連絡用端末で職務の違いを示す。製品・OS・クラウドの実在ロゴや具体的な技術構成は設定しない。試験接続を実店舗の決済や実課金に見せない。

共闘は誰かの背中を照らす巨大画面より、隣へ渡す記録、返答を聞く手、役割が分かれた机で表す。OPS-17は水野が連絡、相原が復旧、現場が照合する一つの危機。眠らない個人を救いの象徴にしない。空いた藤堂の椅子には、別案件への移行と相談先が残る。喪失・死亡を連想させる献花や遺影は置かない。

## 物語のトーンを絵にする

- 対立では同じ目線の高さを使い、相手が守る仕事を手元に残す。強い影で誰かを悪役へ固定しない。
- 昼の忙しさは注文を聞く・電話を取る・棚を探す・袋を渡す手の連続で見せる。客にも昼休みや移動の都合がある。
- 決めゴマは発明の画面だけで終えず、弁当が届く、札が次の手へ渡る、返答が届くなどの変化に置く。
- 終盤も擦れや紙は残る。整然とした無人店舗を完成像にせず、人が任せ合い食事を取れる普通の昼を描く。

小道具の形と話数による変化は [小道具設定](props.md)、共通プロンプトは [画風ルール](style-guide.md) を使う。生成履歴と目視上の限界は [担当ログ](../../art/log-world.json) に記録する。
