# 伏線小道具の美術設定

基準は [人物設定の衣装と小道具](../character-design.md#衣装と小道具の継続)、[バイブルの伏線表](../story-bible.md#主要伏線と小道具初出変化回収)、各話台本。以下のトーン濃度は作画の目標値で、生成画像から測った数値ではない。形・素材の未指定部分を補う。札の寸法や規格、実システムの採番仕様は新たに確定しない。

![主要小道具の設定画](../../art/props/01-props-sheet.png)

設定画は形の見本。注文番号・説明文は画像へ詰め込まず、下記の文書を正本にする。「予約台帳」と「二冊目」の二枠は、使用中と保管時の状態を並べたもの。新品の第二巻を発行する事件を意味しない。

画像上の残る差として、小道具図の魚は頭付き、弁当・制服図は切り身になっている。今後の焼き魚は弁当・制服図の切り身を作画基準にする。小道具図の弁当枠は容器・蓋・仕切りの参照に用いる。

### 注文番号の書式と場面間の一致

| 種別 | 文書上の標準表記 | 運用 |
| --- | --- | --- |
| 試験用 | 見出し「試験用」、注文番号「101」。合わせて「試験用・注文101」。 | ENG-17・CON-11・PRO-24で追う一件は同じ101。番号と個数を別欄にし、「顧客ID 101」と誤記しない。試験決済は実課金なし。 |
| 実注文 | 「店舗略称・実」＋その場面の番号。確定例は「青葉・実001」。 | 店舗・営業日・注文を文脈で区別する。これは漫画上の表示規則で、採番システムの全仕様ではない。001を全店で同じ注文に流用しない。 |
| OPS-17／ENG-01 | それぞれの話で指定する別の実注文。 | 台本にない固定番号をここで創作しない。既存画像の028、126、127は作画用の仮番号。既存ページに合わせて再制作する場合だけ、そのページ内の対応として引き継ぎ、他の時点へ広げない。 |

各場面の開始時に「試験／実、店舗、営業日、誰の注文か、番号」を制作メモへ置き、同じ一件の札・控え・画面・棚で揃える。今回の設定画では短い日本語ラベルのみという条件を守り、札の中身を空欄にした。以後の漫画本文で番号の描画が許可された際は上記書式を使う。数字禁止の設定画へ無理に縮小して入れない。

## 連続性の確認

同じ場面の小道具は、置き場所・持ち手・開閉・中身・番号をコマ間で追う。時間経過では汚れを機械的に増やすより、記録の追記、札の受渡し、袋に入る現物を見せる。ペン・台帳・札の退場は、台本の確認と返答の後に置く。

この設定画の全てを一コマへ詰めない。一話の判断を支える一品を寄りで見せ、残りは背景へ置く。生成画像の残る細部の揺れは [担当ログ](../../art/log-world.json) に記録し、本書と [人物設定](../character-design.md) を優先する。
