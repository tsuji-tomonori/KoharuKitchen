## 見つかった相違と採用する扱い

**扱い**：最新の会話第一稿を出発点にし、コマ割り・解説・図・通読推敲・技術監修・作画は未完として扱います。原セルは変更せず抽出に保持します。サブタイトルと旧タイトルも保存します。

### 2. 本文での用語説明と文字量

`02` H列、`07` 14行目には、ページ内で主題の用語を説明する旧設計があります。一方、READMEと `07` ED33以降、`17` は場面と会話を先に読み、解説を分ける方針です。610〜885字＋図1点という旧目安も、漫画の吹き出しだけの文字数ではありません。

**扱い**：本文では行動と結果を描き、五つの補足見出しで用語・理由・条件を説明します。字数を満たすために会話を増やさず、実寸の可読性をフェーズ2で確認します。

## 再現方法

通常の抽出は [data/README.md](../data/README.md) を参照してください。数式を全再計算する確認用コマンドは次のとおりです。

```bash
uv run --with openpyxl python tools/extract_xlsx.py --recalculate --output /tmp/koharu-recalculated
```

今回の照合では、通常抽出と再計算出力の各 `sheets/*.json` の `cells.*.value` を全件比較しました。差分はありませんでした。改行記号「⏎」はデータ値内で実際の改行へ戻しています。検証結果はこの入力ファイルについてのもので、今後追加されるExcel関数一般に対応する保証ではありません。
