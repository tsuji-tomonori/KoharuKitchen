# 調査R2：漫画の技法――演出・コマ割り・表情

調査・参照日：**2026-09-23**。対象：『こはるキッチンの開発日誌』第1部「腹ぺこの約束」。

## 0. 結論と調査の範囲

第1部の課題は、技法が一切ないことではない。空の袋の無言コマ、坂本の手の残像、森の指による無言の冗談など、育てるべき演出がある。主な問題は、**驚き・失敗・判断の瞬間より、最後に記録を示す場面へ大きな面積を与え続けていること**、そして**異なる感情が似た笑顔に収束すること**である。読みやすい教材の整理が、そのまま漫画のクライマックスになっている。

改稿では、まず読者に「遥の自信が崩れた」「坂本の仕事は想像以上だ」「森は何かを見ている」と感じさせ、その後に記録や知識が残る順番にする。[README](../../README.md)の「行動と結果で状況を変える」「勉強は物語の後に置く」「悪役を作らない」と一致する方針である。

## 1. コマ割り：読ませる順番と、感じさせる時間

### 1.1 日本式の読み順と視線誘導

**資料。** 小学館の新人向け講座は、右から左・上から下を基本とし、横のコマ間と段間の差、見開きでの検討、変形ゴマの使い過ぎへの注意を説明している。[S01]

**本作の設計手順。** 各コマの中にも「最初の吹き出し→見るべき顔／手→次の吹き出し→出口」を書く。右上から左下へ対角線を一本引くだけでは、実際の発話順は保証できない。

1. 先に発話順を決め、人物の立ち位置と両立させる。既に決めた店内の位置関係を、吹き出しの都合だけで逆転させない。
2. 同じ段のコマを一まとまりとして読めるようにする。段をまたぐ縦長コマを使う場合は、次に横へ進むか下へ進むかを確認する。
3. 視線・指・白札の動きで、読者を次の情報へ渡す。台帳の罫線や棚のパースが強すぎて、顔から背景へ目を奪わないかも見る。
4. 007コマ2のような坂本→遥→坂本の往復では、最後の坂本の返答を下へ送るか別コマにする。吹き出しの尾が人物や他の台詞を横断する配置は避ける。

初読確認では、第三者にコマと吹き出しへ番号を振ってもらう。同じ位置で迷えば、読者の習熟に頼らず配置を直す。

### 1.2 コマの大きさと時間は一対一ではない

**資料。** 古舘春一は、大きく見せるコマと小さくするコマの両方を試し、すべてを目立たせて平坦にしないと説明する。また、ボールと手を追う視線の経路によって、速度感を切り替える例を語っている。[S05]

**研究。** Ikuta・Wöhler・Aizawaの研究は、日本語漫画7巻を18人が一コマずつ読む実験で、平均閲覧時間と吹き出しの文字数の関係、読者間の速度差、少ない文字でも長く見られるコマを報告した。コマ単位の表示実験であり、紙の見開きの視線や少年読者の反応を直接測った研究ではない。「大ゴマなら何秒」「無言なら必ず長く読む」とは結論できない。[S13]

**提案。** 「作中で経過する時間」「読むのにかかる時間」「主観的に長く感じる瞬間」を別々に設計する。

| 欲しい体験 | コマの使い方 | 本作の具体例 |
| --- | --- | --- |
| 一瞬の出来事が重く刺さる | 大きな絵、短い発話、焦点を一つにする | 佐伯の問いの後、画面を指した遥の指が止まる |
| 作業の速さに追いつけない | 台詞の少ない小コマで動作を刻む | 坂本の受話器、裏返る白札、二本指を順に見せる |
| 一秒を長く感じる | 同じ対象をわずかな変化で反復する | 遥の開いた口→閉じた口→伏せた目。棚は空のまま |
| 日常の時間が流れる | 前後の状態差と場面転換で省略する | 昼の列から、客のいないカウンターへ移る |
| 読者に余韻を渡す | 応答を急がない無言のコマ | 佐伯を見送った遥の背中と閉じたPC |

小コマを増やすと読む行為そのものは増える。「細かく割る＝必ず高速」でもない。003の忙しさは短い動作の連続、001の敗北は同じ姿勢の停止、と役割を分ける。

### 1.3 決めゴマ・大ゴマ・見開き・断ち切り・変形ゴマ

**資料。** 小学館の講座は、コマの意図と構図を一緒に考え、断ち切りや見開きを印象の強化に使うこと、文字を裁断位置やノドへ寄せ過ぎないことを説明する。[S02]

**提案。** 決めゴマは「その場面で最も残したい情報を担うコマ」、大ゴマは面積の大きなコマとして区別する。小さな白札の寄りも、前後次第で決めゴマになる。

| 技法 | 採用する理由 | 本作での使いどころ／注意 |
| --- | --- | --- |
| 大ゴマ | 読者の注意を一つの行動や感情へ集める | 003で坂本が厨房・札・客を同時に見る姿。複数の説明文まで拡大しない |
| 見開き | 一目で分かる広がり、関係、到達を示す | 将来の再挑戦で、厨房から受取口まで一食を渡せた瞬間。巨大なシステム図だけにしない |
| 断ち切り（裁ち切り） | 絵が紙面外へ続く広さや迫力を出す | 昼の青葉店の列、厨房へ向かう坂本。台詞・目・重要な札は安全な位置へ置く |
| 枠を抜く | 人物や余韻を周囲から浮かせる | 遥の初めての強い決意。常用して隣コマとの境界を失わない |
| 斜め・台形の変形ゴマ | 動線や崩れる感覚を強める | 003の遥が作業を追えなくなる一拍。穏やかな会議を一律に斜めにしない |
| 小さな無言コマ | 反応の前に一拍を置く | 005で図の外へ白札が置かれ、遥がまだ答えられない瞬間 |

仕上がり寸法、塗り足し、ノドの安全域は媒体決定時に指定する。現ネームの外余白3%・コマ間1.5%は画像制作上の値であり、そのまま印刷仕様とはしない。

### 1.4 ページめくりを設計する

**資料。** 『パリピ孔明』の小川亮は、見開き左ページの最終コマに、次を開きたくなる絵や台詞を置くと説明している。これは青年誌の実作者による技法であり、少年誌だけの規則ではない。[S10]

**提案。** 本書では次の呼び方を用いる。実際の右・左を管理し、ファイル番号の奇偶から推定しない。

```text
現在の見開き：［左ページ：最終コマに問い／行動の予兆］［右ページ：先に読む］
                                  ↓ 紙をめくる
次の見開き　：［左ページ：結果と次の行動］［右ページ頭：問いに答える見せ場］
```

- **ヒキ**：答えが欲しくなる状態。例：白札を図の外へ動かす坂本の手。
- **めくった右ページ頭の見せ場**：前の問いに絵で応える。例：整った業務の矢印から、一枚だけ外れた白札。
- **その後のリアクション**：遥の視線がPCから札へ移る。ここまでで「見落としていた仕事」の発見を成立させる。

右ページ末→同じ見開きの左ページ頭では、読者に答えが先に見える可能性がある。強いサプライズは紙をめくる境界へ置く。見開き全体の絵が先に飛び込む場合もあるので、「右上を必ず最初に見る」とは想定しない。

現在の第1部READMEは単ページ画像を縦に並べた形式で、物理的なめくりを再現しない。連載版のネームには `掲載ページ／右・左／同時に見える相手ページ／めくり前後` を追加する。紙の見開きとスマートフォンの単ページ表示を別々に確認する。

## 2. カメラと構図：会話を行動として見せる

### 2.1 距離と角度を、伝えたいことから選ぶ

**資料。** 馬上鷹将は、引きで場所・人物関係などを分かりやすくし、場の情緒も示せること、アップで感情や圧力を伝えられることを説明する。[S06] むちまろは見開き内の構図の重複を意識しつつ、各コマで必要な情報を優先すると話している。[S09]

以下の呼称は本作のネーム上の運用。ショットの境界には流派差があるので、名称だけでなく「画面に何が入るか」も指定する。

| 距離・角度 | 主な仕事 | 本作での指定例 |
| --- | --- | --- |
| ロング／引き | 人と場所、動線、孤立・混雑を一度に示す | 008：入口・商品札・列・壁際の遥と森を同時に入れる |
| ミドル／中景 | 相手と物への動作、会話の関係を示す | 002：仕込みを止めずに紙を差し出す受け渡し係。肘と作業台まで入れる |
| アップ | 感情が変わる顔を読ませる | 001：佐伯の問いを受けた遥。眉から口まで。説明用の紙は入れない |
| 寄り／極端なアップ | 判断の根拠や動作の細部を選ぶ | 閉じるPCの指、空袋の底、白札、森の黒鉛筆の止まる先 |
| あおり | 人物・物を大きく感じさせる | 003：遥から見た、仕事の全体を把握する坂本。優越的な嘲笑にはしない |
| 俯瞰 | 配置・制約・距離を分からせる | 007：PC、弁当を包む両手、有限の机上面積を一画面で示す |
| 目線高 | 対等な交渉や理解を示す | 小野寺が坂本の休日にも使える仕組みを望む場面 |

あおり＝常に正義、俯瞰＝常に敗北ではない。まず位置を示す引きがあり、その後どの人物の感じ方に寄るかで意味が変わる。毎コマ角度を変えるノルマも作らない。同じ構図で口元だけ変える方が、心の揺れを読めることがある。

### 2.2 イマジナリーラインと位置関係

**資料。** 嶌田聡「映像文法」は、二人を結ぶ線の同じ側から撮れば画面内の左右を保てること、動きと視線の方向をつなぐことを解説する。映像制作の説明であり、漫画へ適用する以下の運用は本作の提案である。[S14]

青葉店で遥を画面右、坂本を左に置いた会話なら、寄っても遥は左を見る、坂本は右を見る関係を基準にする。机の反対側へカメラを移すときは、二人と机が入る引きや、実際に回り込む動作を挟んで位置を示す。手元の寄りを挟むだけで左右の反転が必ず解決するわけではない。

会話が二人から四人へ増える004では、場面冒頭に座席の小さな平面図をネームの欄外へ描く。厨房口・電話・台帳を目印にし、移動した人物には移動の一拍を用意する。軸を越える演出も可能だが、「誰がどちらにいるか」を再び判断できる絵を置く。

### 2.3 「顔の並べ」を避ける会話

次は、本作の005を題材にした**構成案**である。

1. 遥が図を差し出す中景。坂本は仕込み容器を持ち、体は厨房へ向いたまま。
2. 坂本の視線の先にある作業台。説明のために止めている仕事が分かる。
3. 水野が白札を図へ置く手元。話の基準が変わる。
4. 小野寺の目が「集計」へ、坂本の指が「受取」へ向く。二人の関心の違いを構図で分ける。
5. 図の外へ残った白札の寄り。遥の手は伸びかけて止まる。
6. 遥のアップ。次の問いを自分の言葉で出す。

顔を物へ差し替えるだけでは単調さは解消しない。物が動くことで発話の意味や主導権が変わるようにする。背中は、002で会議を離れて仕込み場へ向かう決断、001で佐伯を見送る無力感に使える。資料を常に読者へ正面提示すると「説明会の記念写真」になりやすいので、読ませる箇所だけ別に寄る。

## 3. 感情の演出：表情を状況と人物の両方に結び付ける

### 3.1 表情は顔のパーツだけで決めない

**資料。** 篠原健太は、台詞と絵のテンションがずれると笑いを損なうこと、台詞の奥にある意味と表情の関係を考えることを述べる。意図して一致させない演出もあるという説明まで含む。[S07] むちまろのインタビューも、その人物がその状況で何を思うかを想像して表情を詰める話になっている。[S09]

**書籍の公開抜粋。** 『デジタルイラストの「表情」描き方事典』の抜粋では、眉・目・口だけでなく頬や下まぶた、肩・手による強弱を扱い、誇張がギャグの印象につながる場合も示している。[S12]

**本作用の表情案。** 以下は普遍的な感情判定表ではなく、演技を描き分けるための選択肢。汗や頬線は全員に常設しない。

| 場面と感情 | 眉・目 | 口・汗・頬 | 体と視線の補助 |
| --- | --- | --- | --- |
| 001、画面を見せる遥の早合点した自信 | 眉は開き、目は相手を確認する前に画面へ | 明るい口角。汗なし、頬線は弱く | 前のめり。指だけ先に動く |
| 同、佐伯の問いを受けた遥の停止 | 眉の動きが止まり、視線が画面から空棚へ | 口角が落ち、口を閉じきれない。汗は一滴までの案 | 指・肩・重心も止める。笑顔に汗だけ足さない |
| 佐伯の時間切れへの焦り | 眉の内側を少し上げ、目は時計と出口へ | 小さく開く口。頬の装飾は抑える | 財布を持つ指に力。礼儀を守りつつ体は出口へ |
| 坂本の申し訳なさ | 眉を寄せ過ぎず、目は客へ | 小さく結んだ口。必要なら短い息 | 弁当を両手で扱う。安心させる微笑でも深い満面の笑みは避ける案 |
| 004、質問が空回りする遥 | 眉の内側が下がり、目は空欄へ | 結んだ口、浅い息。汗は必須でない | 質問紙を少し引く。相手を詰問する姿勢にしない |
| 005、見落としに気づく遥 | 目が白札へ焦点を結ぶ | 驚きの小さい口→言い直す口 | 握り拳で喜ぶ前に、自分の図を見直す |
| 006、小野寺の懸念と配慮 | 目は休日表から坂本へ | 落ち着いた口。照れ用の頬線は不要 | 台帳を閉じかけた手を止め、相手の返事を待つ |
| 008、森の観察と乾いた冗談 | 観察中は客へ。冗談時だけ遥へ戻す | 観察中は閉じた口、冗談は小さな片側の口角 | 四本指を上げる手は静か。常時明るく説明する笑顔にしない |
| 007、同じ食卓につく安堵 | 眉とまぶたの緊張を解く | ここで自然な笑顔を解放する | 肩を下げ、PCから箸へ持ち替える |

### 3.2 ネームに書く「感情の因果」

各重要コマへ、`きっかけ／本人の欲求／直前→現在の感情／隠す感情／視線先／手の状態` を短く記す。

例：`001・問いの直後：助けになるつもりが役に立たない／役立ちたい／自信→羞恥と停止／言い訳したい気持ちを飲み込む／空棚／PCを指した指が止まる`。

「困り顔」「笑顔」だけを指示すると、同じ表情が別の場面へ流用されやすい。笑顔にも、自信・接客・取り繕い・安堵がある。坂本の接客の微笑と、007の昼食の笑みを描き分ける。台詞に反する顔を使うなら、嘘・気遣い・強がりなどの理由が前後から伝わるようにする。

### 3.3 リアクションの誇張とデフォルメ

**提案。** 誇張する対象を決める。003では「八つくらい」に追いつけない遥の肩・目・ペンの停止を大きくする。坂本の熟練まで大げさな魔法として描くと、何をしたかが読めなくなる。

- ちびキャラやギャグ顔は、読者が事態を理解した後の緊張の解放に使う。004の回数の冗談、008の三本指と四本指の食い違いが候補。
- ギャグ顔に移る前に、何に反応したかを通常の絵で見せる。戻るときには同じ小道具や立ち位置を残し、場面が変わったと誤読させない。
- 001で弁当を受け取れない佐伯の困りごとを、遥のちび顔の笑いで打ち消さない。袋詰めが済んだ後にも、まず客の時間を尊重する。
- 森の四本指は通常の等身でも面白い。全員を同時に変顔にせず、森の静けさと遥の大きな反応の差を使う。

### 3.4 モノローグと沈黙

モノローグには、絵だけでは分からない期待や誤認を担当させる。003の「一度で追える」という期待は、次の動作に破られるので働く。一方、見えている手の停止を「私は驚いた」と重ねて説明する必要はない。

001の袋のコマは会話を止める良い素材だが、袋詰めという作業の省略を埋めるだけにも読める。前に止まる指、後に佐伯へ渡す手を置けば、「画面の提案から、今できる仕事へ移る」沈黙になる。無言コマは、前後に何が変わるかまで設計する。

## 4. 効果線・描き文字・吹き出し・台詞量

### 4.1 効果を置く理由

**資料。** 小学館は集中線、スピード線、ベタフラッシュを異なる役割として説明し、効果背景を心理にも使えるとする。[S04] 描き文字についても場面に合う書体と、背景に埋もれない処理を扱う。[S03]

以下は本作の選択案。効果の追加数を「少年漫画らしさ」の指標にしない。

| 手段 | 本作で担わせる役割 | 避けたい使い方 |
| --- | --- | --- |
| 集中線 | 005の図の外にある白札へ、遥が注意を向ける瞬間 | 毎回、話者の顔へ同じ強さで集中させる |

描き文字は音源と動きのそばへ置き、吹き出しの順番を妨げない向きにする。「プルル」は作業を割り込ませるので強くできる。「パサ」「コト」は手元の小さな音として絵を補助する。衝撃の無音コマに「シーン」を必ず入れる必要はない。小さな音、音の欠落、次の大きな音の差を使う。

### 4.2 吹き出しの形と文字の予算

**資料。** 小学館の講座は通常会話・叫び・内語などの形の使い分け、話者の近くへの配置、文節での改行、長台詞の分割を説明する。[S03] 今回確認した資料から、少年漫画全体に共通する「1コマ何字まで」という上限は確認できなかった。

**提案値。** 本作のネームを作り直すときは下表から試す。台詞・内語・説明枠を合算し、読ませる紙面・画面の文字は別欄に数えて、両方の負荷を見る。句読点も数える。吹き出しを分割しても文字の総量は減らない。

| コマの仕事 | 1コマの発話等の試行目安 | 運用 |
| --- | --- | --- |
| 沈黙・衝撃・動作の決め | 0〜20字 | 物や顔を読む時間を残す |
| 通常会話 | 20〜50字 | 1〜3個程度の吹き出しから設計する |
| 情報整理・複数人の会話 | 50〜80字なら要見直し | 二つの判断があれば分割。絵で伝わる説明は除く |
| 80字超 | 原則として構成を再検討 | 禁止値ではないが、小ゴマへの詰め込みで処理しない |

吹き出し一つはまず10〜25字程度を試す。既存ネームの「約15字以内」はこの作品の制作指示であり、業界の絶対条件ではない。短い文を大量の吹き出しに分けると、顔や動作のための場所を奪う。最終判定は掲載サイズでの読みやすさ、発話の自然さ、表情の面積で行う。

通常の楕円は落ち着いた会話、尖った形は強い発声、尾のない枠は遥の内語、と作品内の対応を決める。ギザギザを「重要な情報だから」という理由だけで使わない。佐伯の問いは静かな困惑のままでも刺さる。文字を縮めて一コマに押し込む前に、発話の役割を減らす。

### 4.3 ネームで終わらせておく確認

画像生成前に、棒人間でもよいので実際にコマ・顔の向き・吹き出し・文字を置く。現在のMarkdownネームは詳細な絵コンテ指示だが、紙面上の視線経路と表情の連続は文章だけでは判定し切れない。

同じ場面を「絵のみ」「台詞のみ」「合わせた状態」で確認する。絵のみで何が変わったか分からなければ動作を足す。台詞のみで説明が重複していれば削る。合わせると意味が変わるなら、意図した強がり等なのか、単なる不一致なのかを判定する。

## 5. 少年誌らしい熱さ：判断が世界を動かす瞬間を描く

**資料。** 外薗健は、既に提示した要素から決めゴマの映像を探り、その要素を際立たせる背景や小物を考えると説明する。[S08] マガジン第112回新人漫画賞では、『BLUES JETS』の全身を見せる試合描写・決めゴマ・表情、『イブと煩悩』の仕草や台詞による人物の魅力が評価されている。同時に、別作品も含め主人公の能動性や応援できる工夫への指摘がある。以下は講評の要約であり、受賞作全編の分析ではない。[S11]

この調査から本作へ引く方針は、画面を強くするほど「何をしたか」「誰の役に立ったか」を明確にすること。怒鳴る先輩や悪い店長を追加しなくても、遥の思い込みと現実の差を大きくできる。

| 演出 | 必要な準備 | 本作への適用案 |
| --- | --- | --- |
| 見開きの決め | 誰が何を待っているか、どこで詰まるかを先に見せる | 将来の再挑戦：厨房の返事→白札→弁当→受取客の手が一つの流れになる。顔や注文の識別情報をノドに置かない |
| 逆転の瞬間 | 敗因を読者が知り、使える手掛かりを既に見ている | 003：坂本に追いつこうとして失敗した遥が、返事を待つ手の停止を見つけて問いを変える。新機能の突然完成で解決しない |
| 決め台詞 | 直前の迷いと、直後の行動がある | 新規案「画面じゃない。この一食を渡す。」を、PCを閉じて袋を取る動作と結ぶ。使うなら人物の口調と場面の自然さを再検討する |
| 登場シーン | 能力や価値観を一つの行動で示す | 森は黒鉛筆の先と列を見る目から、全身へ。蓮はCON-29の温かいお茶と完成した試作画面の差から登場させる |
| ライバルの対峙 | 二人が同じ課題で競っていること | 遥と真柴蓮を同じ目線高・近い大きさで向かい合わせ、同じ条件の紙を間に置く。蓮の速さは本当に有効な強みとして描く |
| 共闘への構図の変化 | それまでの対立構図を読者が覚えている | 向かい合う二人から、同じ側で試験注文札や接続箇所を見る二人へ。協力を握手の台詞だけにしない |

逆転は「正解を聞いた」では足りない。遥自身が見つけ、試し、相手の手や客の行動が変わるまでを見せる。第1部の時点で解決しない問題は、問いの精度や観察姿勢の変化を小さな勝ちとして描き、予約問題そのものを解決済みにしない。

## 7. 今後ネームで使う技法チェックリスト

### A. 場面を割る前

- [ ] この場面で読者に感じてほしいものを一つ言える（焦り、圧倒、悔しさ、発見、安堵など）。
- [ ] 遥など視点人物の欲求、障害、自分で選ぶ行動、結果がある。
- [ ] 決めゴマにする行動を先に決めた。「最後のコマだから」という理由だけで大きくしていない。
- [ ] 学習用のまとめと、物語上の決着を区別した。未確認のことを解決済みにしていない。

### B. コマ・ページ・めくり

- [ ] コマと吹き出しの順番が、初見で一通りに読める。
- [ ] 右・左ページと、同時に見えるページを指定した。
- [ ] めくり前の問いに、次の右ページ頭の絵が応えている。
- [ ] 見開きの答えが前ページから先に見えない。重要な顔・札・文字をノドへ置いていない。
- [ ] 大小の差が感情の差に対応している。資料の文字量だけで大きさを決めていない。
- [ ] 無言コマの前後で、視線・判断・物の状態のどれかが変化する。
- [ ] 断ち切り・変形ゴマには目的があり、読み順を壊していない。

### C. カメラと行動

- [ ] 現場の問題を理解するための引きがある。入口・商品札・厨房など必要な位置が分かる。
- [ ] 大切な感情の変化を読める顔の大きさがある。
- [ ] 手・物・背中のコマが、発話の内容や関係を進めている。
- [ ] 位置関係・視線方向・動きの方向がつながる。軸を越える場合は配置を示し直した。
- [ ] 同じ構図の反復は意図的である。単なる顔と紙の並列になっていない。
- [ ] 一コマに複数の時間の動作を入れる場合、残像・動作線・物の状態で区別できる。

### D. 表情・声・沈黙

- [ ] 各重要コマの「きっかけ→感情→体の反応」を書いた。
- [ ] 眉・目・口・汗・頬・肩が、同じ演技を支えている。
- [ ] 台詞と表情がずれるなら、強がり等の意図が前後から伝わる。
- [ ] 接客の微笑、自信の笑顔、安堵の笑顔を描き分けた。
- [ ] 被害や失敗を見せる前にギャグ顔で軽くしていない。誇張の強さが出来事に合う。
- [ ] 森の沈黙を常時にこやかな説明顔へ変えていない。
- [ ] モノローグは見えている動作の重複説明ではなく、期待や誤認等を加える。

### E. 効果・文字・完成画像

- [ ] 集中線・スピード線・ベタフラ・トーンの用途を説明できる。
- [ ] 描き文字は音源と動きに対応し、読むべき順番と焦点を妨げない。
- [ ] 発話等の字数と、紙・画面上の読ませる文字を別々に点検した。
- [ ] 長台詞を分割した結果、吹き出しで表情や手が隠れていない。
- [ ] 掲載サイズで文字と手の本数が読める。文字の縮小だけで収めていない。
- [ ] 台詞を隠しても、その場面の失敗・発見・変化が読み取れる。
- [ ] 仕上げ後も「ネーム通り」と思い込まず、感情・コマ順・物の状態をPNGから再確認した。

**レビュー方法の提案。** ネームを知らない人に、①読む順、②遥の気分、③誰の何の行動で変わったか、④次を読みたくなる箇所を答えてもらう。正解の説明を先にしない。試読は今回未実施なので、本稿の改善効果は改稿後に検証する。

## 8. 本作にどう適用するか：次のネームで試す具体案

### 8.1 最優先：001を「助けたいのに、助けになっていない」体験にする

ページ増を認める連載版で、現在の001の内容を次の3ページへ配分する案。P1は**左ページ**、めくったP2は**右ページ**、P3はその左と明示する。号内の開始位置によって、この前に別のページが必要になる。

### 8.2 次点：003の見せ場を、記録から坂本の判断へ移す

003では、最初の三工程の説明を簡潔にし、電話・札・厨房・指の連続を描く。遥がノートを書こうとして間に合わない姿を入れる。その後、昼営業後の再現で**坂本の手が止まる**ところを最大のコマにする。

厨房から返事がない方向へ坂本の目線を向け、白札を返しかけた指を止める。遥はその手を見て問いを出す。「厨房の返事を待つ」という追記は、小さなコマで十分読める。未確認の「札」「指」の紙片を残せば、達成と次の課題が同居する。坂本を負かす回ではなく、遥が初めて熟練の判断へ近づく回にする。

### 8.3 005・008で「紙の説明」を「見つける漫画」へ変える

005は白札を主人公の視線の中心に置く。図の外へ札が出る前に、遥の満面の成功顔を置かない。坂本の問い→外れた札→遥の手が止まる→次の質問、という反応の鎖を作る。未受渡し札の扱いは未決のまま残す。

008は一度だけ店内全体を見せ、読者も商品札の前の停滞に気づけるようにする。森の黒鉛筆→列→遥の見直す目→営業後の記録の順にする。第1部では赤いペンや赤札を先取りしない。三つの観察時刻はネームでの作画補完であり、新しい確定設定にしない。最後のクリップの音は観察の終わり、遥の入口への視線は次の観察の始まりとして使う。

### 8.4 蓮の登場で、後の熱さの構図を仕込む

CON-29では既存の「実演開始から三十分」と温かいお茶を生かす。湯飲みの湯気→完成した試作画面→蓮の手→遥の顔、と見せ、速さを体感させる。対峙は同じ条件の紙を挟んだ対等な構図にする。後の接続・共同修正では二人を同じ側から描き、手が別々の作業を担う形へ変える。この構図の変化で、READMEの「一人で解決する人から、仲間へ託せる人へ」を絵として積み上げる。
