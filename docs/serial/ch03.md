# 第3話「三十分の、向こう側」

本文19ページ／2か月目第1週、比較当日の本部15:00〜17:00→翌日の駅前12:06。第5回改稿。主素材：REQ-05、ECO-01、CON-29、ECO-04。REQ-06は次話への入口。

前話末で迫った変更の結果をP01で返し、同じ日の一席を決着させる。勝負の三札は代理／変更／確認待ち。端末手前を未通過、奥を通過済みの同じ配置にする。青葉の相談先は両案にある。駅前の担当欄だけ空いており、両案を同じ条件で補足する。遥は変更後の受取人を別の受取画面へ出すまで追い上げるが、再表示で古い連絡へ戻る。最後まで表の変更札一枚が残る。小野寺が蓮へ次の試作枠を渡し、遥の自作拡張予定が外れる。

奇数右／偶数左、全ページ単ページ。P07・11〜14・18〜19を大きく、会話と操作を5〜6コマで圧縮。P13の札を出す手はページの4分の3。二人は対面のまま各自の案を直し、初めて同じ側に立つ共闘は後の第27話へ残す。本番の予算3,000万円・6か月目の二店公開は第15話以降で扱う。ここでは架空注文の試作を選ぶ。三十分は第1話の実演時間であり、本話はその速さの先にある二時間の勝負。

決め台詞はP15の遥「名前は、譲りません」。P13〜14で札と仕事を差し出した後にも残る愛着の頂点とする。重点めくりはP04→05、P06→07、P10→11、P12→13、P18→19。P03〜04で共通補足を終え、旧P07〜17をP05〜15へ移す。末尾四頁は補充確保と今の箱の受領、二人分を求める客、予約も取り下げる手、隣店へ照会する遥の一手。順次受付の不足は第4話冒頭の短い開発側カットへ移す。

ページ末の誘導（同じ見開き内）：話末のヒキ：客が別の店へ行く前に、遥は二人分そろう道を作れるか。第4話P01は最初の台詞で確約を保留し、客が待てる時間を得て青葉へ照会する。隣店の在庫・運搬・客の了承はそれぞれ実際の返答で決める。
