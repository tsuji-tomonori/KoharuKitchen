## 読者に約束する面白さ

**手順の食い違いを見つける若手エンジニア・青井遥が、八店舗の「その人にしかできない昼」を攻略し、店長全員が同じ日に休める店を作る十八か月。**

今週の問いは「この条件で、誰の手を空ければ勝てる？」。読者は箱・名前・時計を先に見る。遥がどこを変えるかを当て、実物の流れが変わるところで答え合わせする。見つけた一箇所を仲間へ渡した瞬間に、仕事全体が動く。最後には空いた手で、その人が食べる・帰る・球場へ向かう。

長期目標を「八店の店長が同じ日に昼を休む」と明言する。代行者、必要人数、予算、相談窓口を整えた通常の休日で達成する。管理職を一斉に追い出す試験ではない。最終日は遥も客として座る。勝利の最終形は、主人公が活躍しなくても困らない昼。

## 主人公の技「一手戻し」

制作上の呼称。作中では森が一度「また一手戻すのね」と呼ぶ程度。遥は技名を叫ばない。決め動作は二本の指で道筋を追い、片方を止め、実物を一つ前へ戻す。右こめかみの平行な白ピン二本と形を呼応させる。

1. **追う**：一人ではなく、同じ箱・同じ注文を追う。画面へ①②③の手と一本の黒い矢印が重なる。通常は四段階以内。箱を増やす残像にしない。
2. **切れる**：誰が受けたか／何を見たかを確かめられない所で矢印が途切れる。未確認の先は薄い破線、止める一点は太い白抜き円。丸は善悪や失敗者を裁く印ではない。
3. **一手戻す**：空容器・伝票・画面操作で、止まる前と後を再現する。当事者が「そこは違う」と訂正できる。未来を透視している演出にしない。
4. **つなぎ直す**：一つの順番・置き方・担当だけを変えて、他の人に通してもらう。決めの後には必ず現実の手を描く。矢印がつながるだけで成功扱いしない。

### 第1話の三段階

| 回 | 見える事実 | 遥の発見 | 限界・結果 |
| --- | --- | --- | --- |
| 初出P03 | 模擬の一箱に電話予約と店頭販売の二つの手 | 記録しても、箱の行き先は変わっていない | 熟練者を一瞬驚かすが、実営業の手は追えない |
| ピンチP29〜30 | 三本の流れが遥の二本の手へ集まる | 丸の中心は自分。自分が帯を巻く方式では詰まる | 観察力だけでは同時に三つを持てない。仕事を渡す必要がある |
| 決めP37〜38 | 最後の一箱が厨房から店頭へ渡る直前 | 箱を離す前に、受けるアキへ行き先を渡す | アキが既に練習した帯を巻く。厨房も応答して初めて成立 |

視界は白黒の少年漫画の表現。超能力、浮遊する実体の画面、正解の自動表示ではない。聞き逃し、遮蔽、本人の思い込みには負ける。後のソフト回では同じ注文の入力→保存→他画面→再表示を追う。コードの文字量で強さを表現しない。

## 毎週の勝負の形式

総称は制作側の「昼の引受け戦」。店舗に秘密の競技組織を作らない。仕事の担当決定、試作比較、引継ぎ試行の場面で、対戦相手・期限・成功条件・失敗時の扱いをその都度言葉にする。

| 必須部品 | 読者に見せるもの |
| --- | --- |
| 相手 | 今の方法でその仕事を守っている強者。坂本、蓮、森、立花、藤堂、以前の自分 |
| 守る人 | 今回の客／担当者の一つの予定と具体物。椅子、切符、配る前の自分の弁当 |
| 制約 | 一つを大きく。「店長の代行なし」「作者は触れない」「通信が戻るのを待てない」 |
| 公開した手掛かり | 最低三つ。解決に使う物・動作・相手の得意技を、決める前に出す |
| 判定 | 森は事実を記録。業務判断は店長、計画は水野、投資は小野寺。客は食べる側で、開発者の人格を採点しない |
| 得るもの | 次の担当、試作一枠、採用、他者の予定が空くこと |
| 失うもの | 今回の担当候補から外れる、好きな機能を諦める、自分の案を相手へ渡す。給与・雇用・客の昼を賭博の賞品にしない |
| 勝った後の反転 | 今回の成果を保持したまま、新条件を一つ加える |

通常19頁：P01〜03で今回の一食と条件、P04〜07で得意技の小成功、P08〜11で制約が刺さる、P12〜16で仕掛けの答えと実行、P17〜18で生活の回収、P19で次の一手。毎週の説明を定型札の読み上げにせず、客の台詞と相手の注文で自然に渡す。笑いは通常回2〜3箇所、初回5箇所以上。謝罪と食事の余韻には重ねない。

## 初戦の条件と仕組み

相手は坂本。挑戦は「坂本が兼ねている予約受取を、別の人が回せるようにする」。店長が妨害する対人競技ではない。P02で翌日の12:00〜12:20、予約を全件、約束時刻に正しい相手へ渡す条件を宣言。P16で翌日の対象を六件へ確定。時刻は12:04、08、12、16、18、20。最後の一件が佐伯のから揚げ。

坂本は通常販売と電話を担う。調理・会計・通常のスタッフ連携は利用可。予約の捜索、照合、受渡しを坂本が肩代わりしたら今回の試験は不合格。必要なら即座に呼ぶ。**助けを呼んだことを叱らず、呼ばずに誤配したらより悪い結果になる**。店長の介入は客を守るためいつでも可能。判定のために救援を遅らせない。

勝てば翌週の受取改善を担当し、蓮と試作担当一枠を争える。負ければ翌週のその候補から外れ、見学・条件集めを続ける。敗者を店から追放しない。森が六件の受領時刻・内容・介入の有無を記録し、坂本が担当を渡す。試作担当は一週分で、システムの発注や本番採用とは別。

仕組みは三つだけ。

```text
台帳の予約を読む     同じ内容の帯を箱へ巻く        本人の申告と照合して渡す
佐伯／から揚げ／12:20 → [ 予約 12:20 佐伯 から揚げ ] → 受領時刻を台帳へ
                         ↑中身を確認した担当と受取担当が読む
```

帯が単独で机にある状態は、弁当を確保した証拠ではない。箱の中身・帯・台帳が一致して予約棚へ置かれて初めて準備が整う。客前で個人情報の一覧を掲示しない。予約帯を巻いた箱は、通常販売へ移さない。取り消し・代理・変更は別の確認が必要。この未対応範囲が第2話以後の課題になる。

P21で、最初からアキも巻く練習をしている。実営業で遥が抱え込むのは能力不足を隠したい性格の問題。P30以後の分担は、未検証の新ルールの即興投入ではなく、準備したやり方を仲間へ渡す選択。

中村は最後のから揚げを望むが、次の仕込みは配送の出発に間に合わない。予約はまだ成立しておらず、六件の勝利条件へ後から混ぜない。売れないことを早く明言し、別の商品も尋ねるが、本人が選ばず去る。試験に勝っても中村の昼は返せていない。第9話で別の日の昼を返す。

## ライバルと持続する問い

蓮は同じ灯台ソフトの同期。遥が見つけた一件を、他の場所で動かせる部品へ変える。遥の「近くの一人」に対し、蓮は「まだ見えない大勢」。親しさがあるので遠慮なく競える。蓮の速さは本物で、既存部品を使うことを劣った創造性として扱わない。

初回P05で同期の短い通話と一週の枠を見せる。P47以後、架空注文を二つの端末で通し、遥の一店の観察が蓮の複数店へ届く速さに負ける。末尾は双方の案を交換し「明日は作者が説明しない」で確定。第2話冒頭に、受取人だけが替わる同じ注文を入れる。読者は前話の帯がそのままでは使えないと分かる。

シリーズの謎は、八店の古い手順に残る「店長確認」が、店ごとに何を意味するか。失われた万能マニュアルや黒幕は置かない。声が聞こえない、補充が違う、代理が多い、連絡先が古いなど、かつて人が救った穴が積み重なったもの。二店目で同じ言葉の違いを明かし、運用・保守編で過去の合理性までたどる。初日の佐伯の欠品を大陰謀として引っ張らない。

## 画面と名前の規則

奇数右／偶数左。P01〜02が最初の対向面。強いめくりは偶数末→次の奇数頭。初回の一枚絵見開きはP25〜26（正午）とP37〜38（分担による逆転）。受領は単ページで顔と手、食事は白い余白で取る。扉P04も52頁に含む。

Eを会話と食事、Fを手順の再現・混雑・決めに使う。正午は厨房口から入口までの斜め俯瞰。行列の圧力と別々に動く腕で密度を上げる。同じ人物の余分な腕を描かない。

初登場は必ず「姓名／役割」の見出しと、本人から出る台詞を対応させる。呼称は遥／店長／蓮／森さん／水野さん／佐伯さん／アキ。主要人物は初登場後の会話でも呼称を反復し、登場回の見出しだけで終わらせない。厨房の大西は「大西／厨房」の小見出しだけで十分。藤堂・小野寺・相原・立花は初回に顔見せしない。名を増やすことより、手が何をしたかを覚えさせる。

## READMEとの整合

観察・再現・担当分けが、後の要求・設計・試験・運用につながる。第1話の紙は目的を知るための道具であり、紙万能の結論にはしない。二店の伝達、変更の保持、再送、権限、保守ではソフトを作る意味を実物の成果で見せる。初回末で既にコードを組む蓮を見せる。

本文に専門用語の定義を置かない。今回の帯、試験、人物史、数値は創作。SWEBOKの規定として述べない。教材用補足・原文対応は次工程で既存資料へ照合し、漫画の後ろに置く。このラウンドでは技術解説を追加して本文を膨らませない。

旧稿との差分、調査からの採用対応、厳しめの採点は[記録](round-01-notes.md)。上位3位・90点は目標であり、完成原稿の評価を先取りしない。
