## 1. 青井遥 — 自分の手で間に合わせたい人

23歳、156cm。灯台ソフト入社2年目。実装は速いが、店の経験は初めて。

- **背景・家族・傷**：母は町の衣服直し店で働く。父は路線バスの整備担当。高校時代、忙しい母のために休憩通知を作った。通知は鳴ったが、受けた仕事を代わる人は増えず、母の椅子は空いたまま。母は使おうとしてくれたからこそ、「喜ばれた」と「助けた」の差を見ないで来た。家族は健在。衣服の型紙や父の工具の並びを、幼い頃から手順として写して遊んでいた。
- **なぜこの仕事か**：一度作ったものが、離れた人にも届くことが好き。母の通知の失敗をまだ「もっと便利なら解けた」と解釈して入社した。
- **want**：自作を使ってもらい、蓮にも店長にも勝って、自分の名前の担当を取る。
- **need**：自分がいなくても、他の人が判断できる材料を渡す。人に使われると、自作が変わることも受け入れる。
- **欠点**：見栄を張り、質問より先に正解を言う。自分でやった方が速いと言って仕事を抱える。善人であっても、相手の手を奪う。
- **得意技**：「一手戻し」。見た動きを順序に分解し、その場の物ですぐ再現できる。未確認の情報、調理、接客の全体速度は不得意。観測と推測の線種を分ける。
- **口癖・決め動作**：「一回、戻していいですか」「今の、もう一度」。二本指で追い、片方の指を止める。勝ちたい時は袖を一折り余計にまくって左右がずれる。
- **関係**：坂本には速度で負ける。森には自分の嘘を見つけられる。アキには長い説明を短くされる。蓮の速さを一番よく知るため、軽口一つでも燃える。水野には仕事を取りに自分から交渉する。
- **好きになる理由**：作れたときの笑いを隠さない。負けは悔しがる。自分を囲む丸を消さず、助けを頼める。料理は普通で、余計な万能属性を足さない。
- **ジャンプ読者への自己点検**：成人女性を少年化する必要はない。前進する欲、弱点、技の発動、負け顔があるかが核心。教訓の代弁者になれば失敗。第1話で「私が全部」の失敗を実際に負わせる。
- **デザイン**：大きいが丸すぎない目、太めの短い眉、頬を残す顎。黒髪は襟足の小さい三角の尾。本人右こめかみの白ピン二本を従来より太く、指二本と同じ間隔で見せる。白い丸首、薄灰の袖まくりカーディガン、白い胸当てエプロン、大きい角ポケット、濃い細身パンツ。成人の首・肩・手。布は身体に張り付かせない。
- **表情4種**：得意げ／歯を食いしばる悔しさ／視線が一点に合う集中／白目と大口の見栄崩壊。全て同じピン・尾・輪郭。
- **過去の開示**：P13〜14の一場面だけ。通知を作る高校生と空いた母の椅子。父の説明や家族集合回想は初回へ詰めない。

## 2. 坂本誠 — 最後まで手を離せない強者

48歳、180cm。青葉店長。黒い大きな四角がシルエットの中心。

- **背景・家族・傷**：調理補助から上がった。以前、自分の曖昧な引継ぎで代理店長に注文の行き違いを背負わせた。それ以来、任せるより自分が回す方へ寄った。妻は書店勤務、息子は中学生で少年野球を続ける。妻を家庭の待機係にせず、夫婦それぞれ勤務を調整して観戦している。
- **なぜこの仕事か**：学生時代、働く時間の合わない父へ弁当を渡した記憶。料理の評価以上に、間に合った顔を覚えている。
- **want**：今日の客を待たせず、日曜の息子の決勝を最初の球から見る。
- **need**：自分が知る例外を言葉にし、任せた人が自分と違う手順を選ぶことを認める。
- **欠点**：手際の良さで説明不足を覆う。「いつも通り」が他人にも通じると思う。自分の介入を失敗の隠し蓋にする。
- **得意技**：次に空く手を読み、電話・袋・会計を一筆書きのようにつなぐ。ただし二つの場所の現物を同時に保証はできない。
- **口癖・動作**：「頼む」「それ、誰の分だ」。片手は相手へ開いて、もう片手で仕事を続ける。受けた仕事は掌を返して引き寄せる。
- **関係**：遥の相手であり、負けて手が空くことを望む人。アキを信頼しているが、困らせたくなくて予約を渡してこなかった。森には試験の停止権を自分から共有する。蓮の画面も役立つなら使う。
- **好きになる理由**：口数より先に弁当を出す。自分の判断の誤りを客へ自分で詫びる。負けると悔しいが、担当を渡す約束は守る。
- **少年誌点検**：主人公を叱るだけの上司では弱い。まず腕前で圧倒し、最後に大きい手が空く一枚を報酬にする。罰は雇用ではなく今回の担当適性。
- **デザイン**：四角い顎・幅広の鼻・太い水平眉。角刈りの両こめかみに白髪。白ポロ、黒ベタの胸当てエプロン。左胸に「店長 坂本」。髭は付けない。腕の太さと指の器用さを両立する。
- **表情4種**：仕事中の平静／本気の集中／不器用な笑い／説明を省いたと気づく困り顔。威嚇顔で格を作らない。

## 3. 真柴蓮 — まだ会っていない店まで届かせたい人

23歳、174cm。灯台ソフトの別案件担当。遥と同期。水野が調整した短い支援時間だけ参加する。

- **背景・家族・傷**：両親は地方の小さな食料品店を営む。姉が店を手伝う。学生時代、家の集計を自作したが、離れて暮らし始めたら更新が止まり、姉が紙へ戻した。自分だけが直せる仕組みの弱さから、既存部品と共通の作り方を好むようになった。
- **なぜこの仕事か**：家一軒へ作るだけでなく、同じ困りごとのある店に早く届けたい。
- **want**：次週の試作担当を取り、遥が一店を観察している間に二店へ届かせる。
- **need**：同じ表示でも店によって意味が違う。部品の完成速度だけで利用結果を見切らない。
- **欠点**：条件がそろった試験を世界の代表と見なしやすい。早く助けたいので、説明の遅い人の未整理な話を要約しすぎる。
- **得意技**：既存部品を組み、入力側と受取側の二つを同時に動かす。遥の一件を広げる。未知の厨房事情を遠隔から当てる力はない。
- **口癖・動作**：「触ってみて」「そっちも同じ条件で」。出来た端末を180度回して渡す。温かい茶を飲む前に一つ動かし、失敗時は茶を置く。
- **関係**：研修で遥が一晩悩んだ不具合を再現し、蓮が既存部品の設定を直して通した。以来「気づくのは遥、動かすのは蓮」が互いに気に入らない。森の試験は頼れるが怖い。水野の時間枠は守る。
- **好きになる理由**：相手のよい手をはっきり認め、借りる。手加減はしない。負けても相手の仕事を壊さない。
- **少年誌点検**：勝ち組の軽薄な男へ寄せない。P48で遥の帯に興味を示し、P52では自分も試される条件を受ける。恋愛の含みでライバル性を代替しない。
- **デザイン**：少し長い三角形の顔、横長の目、片眉が上がる。短い跳ね髪は明るい網点で、黒髪にしない。白い開いたシャツの二本の縦線と黒T、細いパンツ。遥の閉じた白いエプロン面と、蓮の開いた白い縦線を対比。PCは無地。
- **表情4種**：親しい軽口／計算外の驚き／静かな集中／口を曲げる悔しさ。助力時だけ善人の別顔にしない。

## 4. 森理沙 — 失敗する客を、自分が先に演じる人

28歳、162cm。品質・テスト担当。

- **背景・家族・傷**：両親と年の離れた弟がいる。弟がイベントの受付で何度も列を移らされた際、説明が正しくても使えないことを知った。新人時代には、確認できなかった点を小さく書き、公開後の問合せで初めて重さを知った。出来事を弟の属性による問題にせず、案内と手順の問題として記憶する。
- **なぜこの仕事か**：「普通なら分かる」で抜けた人の役を、先に引き受けたい。
- **want**：客に起こる前に全ての失敗を見つける。
- **need**：全部は調べきれないと示し、他の人へ試す役と判断を分ける。
- **欠点**：止める根拠を一人で集め続け、自分の食事と相手の次の試行を忘れる。
- **得意技**：同じ一件の順序を一つ変え、成功条件の穴を示す。第1話では誘導せず記録し、第2話では強敵になる。
- **口癖・動作**：「今の、誰が確かめた？」「順番を変えます」。鉛筆を一度止め、相手が答えるまで待つ。初回は黒鉛筆、赤ペンの白帯二本は第2話から。
- **関係**：遥の観察を尊重するが、思い込みの線は消させる。坂本も同じ基準で見る。水野とは、条件を減らすことと失敗を隠すことの違いを話せる相手。
- **好きになる理由**：人の失敗では笑わず、自分の受取忘れでは言い訳をする。遥に箸を渡されると素直に受ける。
- **少年誌点検**：検査の解説者でなく、次に何を試すか読者が楽しみにする相棒。丸眼鏡越しに目を見せる。無表情一種類に固定しない。
- **デザイン**：顎で切れる水平ボブ、揃った前髪、細い丸眼鏡、半分ほど下がった上瞼。黒いハイネックと白いストレートパンツ。ペンは口にくわえない。遥より目を小さく、顎を細くする。
- **表情4種**：観察／発見してわずかに笑う／見落としの悔しさ／食事忘れを突かれた気まずさ。

## 5. 水野真紀 — 「任せて」を約束に変える人

34歳、165cm。灯台ソフトの進行責任者。父と妹が別居。パートナーは舞台照明の仕事で、互いの公演・繁忙を予定表へ書き合う。

- **背景・傷**：以前「たぶん大丈夫」と引き受け、店と開発の双方に別の日を期待させた。誰かを怒らせない返事が、後から全員を困らせた経験を持つ。
- **なぜこの仕事か**：腕のある人が、次に何をすればよいか分からず止まるのが惜しい。人の能力が届く日時と範囲を作りたい。
- **want**：全員から頼られ、どちらの願いも実現したい。
- **need**：今はできないことを早く言い、減らした仕事の責任も引き受ける。
- **欠点**：その場の沈黙が苦手で、本人の了承より先に受けてしまう。
- **得意技**：曖昧な頼みを「誰が・いつまで・何を」に揃える。第1話では枠を一週分と明確にする。投資決定は小野寺の権限。
- **口癖・動作**：「ここまでは、約束します」。予定表を胸へ抱えかけてから、相手にも見える向きへ開く。
- **関係**：遥と蓮の競争が片方の過労にならない勤務枠を作る。森の未確認事項を一緒に説明する。坂本の勤務の願いを、応援の費用と日程へつなぐ。
- **好きになる理由**：失敗した部下へきれいな言葉だけを掛けず、外へ説明する仕事を自分が受ける。オフではパートナーの舞台の感想が妙に長い。
- **少年誌点検**：初回は役割を絞り、長い会議をしない。中盤で交渉そのものが勝負になるまで、説明を独占しない。
- **デザイン**：縦長の輪郭、大人の横長の目、長いポニーテール。大きい明色のジャケットの襟、黒インナー、裾の広いパンツ、低い靴。四角い手帳を肘へ抱える。遥の短い尾と脚の細さに重ねない。
- **表情4種**：柔らかい応答／言い切る覚悟／受けすぎた焦り／予定が通った笑顔。

## 6. 佐伯真帆 — 自分の昼を選ぶ人

32歳、160cm。近所の施設の受付勤務。夫は別の職場、娘は小学生。家族の食事だけでなく、自分の好みで生姜のから揚げを買う。

- **背景・傷**：育児休業から復帰したころ、遠慮して休憩を最後に回す癖がついた。今は同僚と交代時刻を決め、自分も休むと口に出し始めている。恒常的な法令違反や搾取を、この店の改善だけで解決したことにはしない。第1話の窓口交代は12:30。徒歩片道2分。
- **なぜこの仕事か**：人が用事を済ませて帰れるのが好き。仕事に誇りがあり、転職で救済される人ではない。
- **want**：12:20に受け取り、12:22に戻って座り、生姜味をゆっくり食べる。
- **need**：店や同僚へ遠慮するだけでなく、自分の待てる時刻を伝える。主人公に成長させてもらうための課題ではなく、本人が既に始めている行動。
- **欠点**：予定を崩したくなくて、待てない時刻をぎりぎりまで言わないことがある。客の落ち度として欠品の責任を転嫁しない。
- **得意技**：自分が欲しいものを短く具体的に言う。開発の専門家ではない。
- **口癖・動作**：「今日は、ここまで待てます」。左腕時計を見てから、相手を見る。食べる時は時計から視線を離す。
- **関係**：坂本には味を信頼している。遥の努力は知らなくても、受け取りが変われば分かる。森の試験に毎回駆り出されない。アキの通常の接客を覚える。
- **好きになる理由**：都合のよい感謝役にならない。嫌だったことは言い、それでも好きな料理を翌日も自分で選ぶ。子供との短い連絡は生活の厚みで、涙を要求する事情ではない。
- **少年誌点検**：主人公が救う抽象的な大人で終わると弱い。空席と一口の対比、好物の具体性で年齢を越えた感覚へ届ける。大泣きや説教を足さない。
- **デザイン**：六角形に近い柔らかい頬、丸い顎、低い弧の眉。肩までの内巻き、本人右に分け目。淡いカーディガン、白ブラウス、濃い膝下のAラインスカート。左腕に小さな丸時計のみ、右肩にバッグ。髪の艶は細線だけ。
- **表情4種**：待つ／困惑を伝える／時間が戻った安堵／一口を味わう。時計の拡大盤面は設定画で不要。

## 7. 小川アキ — 主役の道具を自分の言葉で使う人

21歳、158cm。青葉店の受取係。旧版の小川千夏から改名。初回の決めを共同で担うため、v3設定画の主要7人に加える。

- **背景・家族・傷**：父は配送、母はスーパー勤務。弟がいる。入店初期、長い手順を順番どおり覚えたのに、途中で電話が入りどこまで済んだか分からなくなった。叱られた記憶より、客の前で同じ質問を二度した恥ずかしさが残る。
- **なぜこの仕事か**：作る側と食べる側が会う受取口が好き。将来、自分の担当時間帯を持ちたい。
- **want**：通常販売だけでなく、予約も自分へ任せてほしい。
- **need**：短くした手順の理由と、分からない時の相談先を残す。
- **欠点**：覚えやすさを優先して条件を削りすぎる。「いつも」で済ませたくなる点は坂本に似る。
- **得意技**：長い手順をその場で使う短い言葉へ直す。口だけでなく、言いながら手を動かして確かめる。
- **口癖・動作**：「つまり、こう？」「そこ、私がやる」。袖を肘へ上げ、受ける手を前へ出す。
- **関係**：坂本へ挑む遥に共感するが、遥が仕事を抱えると率直に割り込む。森には自分の言葉で不明点を言う。遥とは教える側が入れ替わる関係。
- **好きになる理由**：主人公の助手で満足しない。最後の箱は自分の判断と練習で受ける。自分の手柄を「遥さんのおかげ」だけで閉じない。
- **少年誌点検**：主役と同年代の近い顔にしない。小柄な主役二人のように見えたら失敗。アキの横幅のある丸髪と、遥の尾・白面で分ける。
- **デザイン**：耳の下までの丸いマッシュボブ、短い横前髪、本人右眉の外端の小さなほくろ。丸い輪郭、上向く短い眉、横に広い笑顔。白ポロと短めの黒い腰エプロン、まっすぐな黒パンツ。名札「小川」。店長の胸当て型とは区別する。新デザインのため旧版の集合画から顔を借りない。
- **表情4種**：平静／歯を見せる快活さ／任せてもらえない不満／箱を受ける集中。

## 関係図と笑いの方向

```text
                  水野（時間・範囲を約束）
                 ／                    ＼
       遥（観察・再現） ← 同期の競争 → 蓮（部品・展開）
        ↑負ける／任せる       ↑同じ条件で試す↑
  坂本（昼の強者） ← 記録と反例 → 森（客より先に困る）
       ↕任せたいが抱える        ↕短い手順を試す
  アキ（実際に使う） ← 道具と教えが往復 → 遥
       ↓同じ予約を渡す
  佐伯（自分の昼を選ぶ）    中村（今日は買わずに出る）

  厨房の大西 → 箱と用途 → アキ／遥
  小野寺 → 投資と人員 → 水野 → 店と開発
  藤堂 ↔ 遥・蓮（設計）／相原（維持できる人数）
  立花 ↔ 坂本（同じ言葉でも違う店）
```

遥の大げさな命名を蓮が短く呼び、遥がむくれる。坂本の三語の説明を遥が八工程へ分け、店長自身も数え直す。森が他人の六件を記録して自分の一食を忘れ、遥が箸を渡す。アキが遥の説明を三語へ縮め、遥が感心しつつ悔しがる。関係の上下は固定しない。佐伯と中村の損失は落ちの材料にしない。

## v3設定画の作画仕様

1人1枚、全身正面・本人右側からの横姿・表情4種。従来の8表情・背面より今回の指定を優先し、各顔を大きくする。横姿は鼻が画面左。正面では本人右のピン／ほくろは画面左。佐伯の左時計を横姿の手前へ移さない。

## 生成後の検収

組み込みimage_genで11回生成し、個人7枚＋集合1枚を採用。坂本・森・佐伯を各1回再生成した。8枚とも目視し、生成元と保存先のPNGのSHA-256一致を確認。画像のリサイズ、色調変更、合成、文字修正は行っていない。

- 坂本：右側面に出ていた遠側の左胸名札を再生成で除去した。
- 森：初回の鉛筆が白帯付きペンになり、誤った小道具名も生成された。再生成で黒鉛筆へ統一し、小道具欄を除去した。
- 佐伯：右側面の手前腕へ移っていた時計を再生成で除去した。正面の本人左腕にだけ残る。
- アキ：正面と表情で右眉外のほくろを確認。横図は左胸名札も見えるため厳密な真横より少し正面寄り。本文の右真横では名札を隠す。
- 集合：7人の人数・順序・衣装の白黒面は明確。数cm単位の身長差は数値表を優先。森の目が丸く、アキのほくろが不鮮明なので、顔は個人画を優先する。
- 残る課題：水野・佐伯の年齢差、遥の尾の三角形はまだ控えめ。一部の髪・靴の白抜き線、頬の薄い線が残る。水野には指定外の短い説明文が生成されたが、本文の設定を変更する根拠にしない。

少年誌での好感度は自己点検であり、読者調査は未実施。設定画で識別できることと、漫画の小ゴマで同じ顔を維持できることは別の検証課題。今回は漫画ページや縮小加工画像を作らず、この限界を次のネーム工程へ渡す。
