# 第10話「正論は、高くつく」

週刊連載版v5・ラウンド6（新規）。2026-09-26。**扉込み20ページ**（見開き1枚を含む）。三か月目の本部。新キャラクター[百目鬼正](character-domeki.md)の登場回。ネームは[manga/serial/v5/ch10](../../../manga/serial/v5/ch10/README.md)。作画は未着手。

## あらすじ

八店の受取画面の試作が動き、本番開発への投資を決める審査の日。小野寺が呼んだ外部の投資審査人・百目鬼は、藤堂の大案を「完成した日に古い」、遥と蓮の試作を「今日、捨てなさい」と切り捨て、最後に遥の夢へ「このシステムを入れれば、店長は今より休めなくなる」と言い放つ。暴論に聞こえた三つの結論は、机の上にあった要件書・帯・相原の夜間通知だけで正論へ組み直され、遥は対局時計の時間切れで負ける。投資は保留。遥は「画面が止まった日の昼」を現物で再演して勝つと決める。

## 前提（第2〜9話は未執筆）

- 第2〜3話で蓮が試作担当を取り、第1話P45の八店用の練習環境を、八店の受取画面の試作へ育てた。画面から帯を印字できる（第1話P45「帯への出力」の延長）。
- 夜間の試作の再起動・復旧は、実際には相原一人が受けている。本話まで作中で問題にされていない。
- 藤堂は三か月前の要件書をもとに、全店統合の大案（十八か月）を準備した。
- 投資の決定権は小野寺。水野は勤務と期限を約束する。
- 藤堂・相原・小野寺が第9話以前に初出していれば、本話の人物見出しは削る。未登場のままなら残す。

## 三つの暴論とフェアな根拠

百目鬼の弁論は[人物設定](character-domeki.md)の三段（暴論→反論の歓迎→現物で組み直す）。根拠はすべて、この回の前半か第1話で読者が見た物に限る。

| 頁 | 暴論 | 組み直した正論 | 先に見せる現物 |
| --- | --- | --- | --- |
| P01〜02 | 「発注係に、椅子を一脚買いなさい」 | 発注ミスは全件、閉店後に立ち通しで打った時間帯。AIは疲れた人の代わりに疲れてくれない | 同じコマのミス一覧の時刻と写真 |
| P07〜08 | 「この案は、完成した日に古い」 | 三か月で一番の発見（帯）は要件書に一行もない。十八か月後の店はまた別の発見をしている | P03の要件書、第1話の帯 |
| P10〜11 | 「三か月の試作は、今日、捨てなさい」 | 試作で買ったのは画面ではなく「名前を先に送れば昼が回る」という答え。答えはアキの手とノートにある | 第1話のアキの帯と空トレー、P03の八台の画面 |
| P12〜17 | 「店長は、今より休めなくなる」 | 店長しか分からない店の代わりに、相原しか直せない店を八つ作っている。八店の店長が同じ日に休めば、止まった日に分かる人がいない。帯を手で回せるのは青葉のアキだけ | P03の相原の隈と「夜間再起動（今月3回目）02:14」、P09の遥の宣言、P13の「画面から印字される帯」 |

最後の暴論は、遥の夢を否定しない。**夢の設計の穴**を示す。その穴は、遥の需要「自分がいなくても、他の人が判断できる材料を渡す」と、第1話P43の「代わる人を育てる方法」へそのままつながる。再戦（第21話想定）で遥が上回る根拠もここに置く。

## ネームへ渡す共通規則

- 奇数右／偶数左。P01・02、P03・04のように対向する。P04が扉。**P15〜16は一枚絵の見開き（値札読み）**。偶数末→次の奇数がめくり。P10→P11（捨てなさい）、P14→P15（夜中の二時）、P18→P19（廊下）でめくりの引きを使う。
- 会議室は窓側から見る固定の軸。**画面右に開発側、画面左端に百目鬼**、奥に小野寺。右→左の読み順で「開発側が言い、百目鬼が返す」。対局時計も画面右が開発側、旗が落ちるのは画面右。
- 演出言語を三つに分ける。遥の視界（網点・白抜きの円・黒丸白抜きの番号・実線と破線）はP13だけ。百目鬼の値札読み（網点が消え、紐付きの白い荷札が下がる）はP14の予兆とP15〜16。蓮の組み上げ（黒地の白線）は本話では使わない。
- 百目鬼の長い弁論は、20字以内の吹き出しを右上から左下へ階段状に連ねる。一つの吹き出しに一文。尾は全部本人の口へ。
- 専門用語を台詞に出さない。「相原さんが一人で受けている夜」「もう払った三か月」で言う。
- 笑いはP02の請求書、P05の弁当、P06の「未確認」、P10の見栄崩壊、P20のドウメキ。P15〜17の論破の決めと、P20の一口のコマには入れない。
- 佐伯・中村は登場させない。客の損失を百目鬼の論破の材料にしない。
- 画風はE（会話・余韻）とF（大口の弁論・見栄崩壊・値札読み）。百目鬼の大口はF、P20の一口はE。

## 自己点検（シナリオ段階）

| 観点 | 判定 |
| --- | --- |
| 一見間違いに見えるか | 三つとも、第一声で主人公側と読者が反発する形にした（椅子／捨てろ／休めなくなる） |
| 正論として反論できないか | 根拠は前半に置いた現物だけ。後出しの資料で勝たない。最後の論点は第1話の夢と遥の傷（母の椅子）に直結する |
| 悪役にしていないか | 攻撃は設計に向け、相原を一人だけかばう。嘘はつかず、決定権は小野寺 |
| 説教になっていないか | 教訓で締めず「以上」と請求で切る。用語を言わない |
| 主人公が格好いいか | 技は完璧だと認めさせ、前提だけを外す。負け顔から、次は現物で勝つと決める顔で終える |
| 残課題 | 第2〜9話の未執筆部分との整合（試作の状態、相原の初出）。百目鬼・藤堂・相原・小野寺の設定画が未作成。見開きの情報量（八店・相原・値札）が多いので、作画時に値札の数を絞る |
