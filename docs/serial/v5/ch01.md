# 第1話「店長、その手を空けてください」

週刊連載版v5・ラウンド3a。2026-09-24。**扉込み48ページ**。初月の初日11:45〜翌日14:30以後。[編集レビュー](review-r2.md)の指示1〜4を反映。主素材はREQ-01〜03、ECO-05〜06、CON-29、ENG-08。人物史・帯・試験・外の工事は創作。

## ネームへ渡す共通規則

奇数右／偶数左、P01〜02から24組。P04が扉。一枚絵の見開きは**P21〜22（正午）とP31〜32（技③）**で、それぞれ全体で1コマ。偶数末→次の奇数が物理的なめくり。P40の椅子からめくってP41の一口を見せる。食事の頁へ笑い・主人公の解説を侵入させない。

Eは通常の会話・余韻、Fは動く手・視界・工事の圧力・大きい負け顔。番号は基本①〜③、実見は実線、未確認は破線、一点を太い白抜き円にする。超能力の客観視点にしない。八工程の詳細図は冒頭だけとし、読者に八つを暗記させない。台詞は各コマ記載順、吹き出しは原則20字程度で区切る。帯の文字・手・顔に重ねない。

場所は南に客側、北西に厨房、北側に予約棚と時計、北東に事務。北西の開口は腰壁と奥行きのある受け渡し台で塞がれた「受渡し専用窓」で、人は通れない。人の入口は北東の事務通路を回った厨房東口だけ。入口の「入室：帽子・手洗い」はこの店の衛生手順。店頭係の店頭手洗いだけでは厨房へ入れない。P06でこの間取り、P12で入室の準備、P19で店頭と厨房の区別を先出しする。大西も仕上げ台を離れて耳元まで来れば盛付けが止まる。P28で両者が窓へ寄っても、深い台を隔てた声が消えることを実演する。台帳は原本一冊。厨房の仕上げ台から包装台へ渡す清潔な浅いトレーを追加する。これは店内の受渡し専用で、客が食べた食器や廃棄容器の戻りではない。帯もトレーも食品へ直接触れない。往路は完成箱、復路は空トレー。二本の道が一画面で追える配置をP17・21・30〜33でそろえる。東側から西向きに見ると、画面右が厨房・大西、左が包装台・アキ。往路は上の右→左、復路は下の左→右。窓に二段の設備を新設する意味ではなく、同じ台の奥側／手前側の動きを図の上下へ投影する。

翌日の予約は全員本人、一箱、品・時刻の変更なし。制作上の予約1〜5の名字は順に田辺・木下・石田・岡田・安田。約束は12:04、08、12、16、18、20。最後だけ佐伯の名を反復する。予約1〜5は制作上の番号で、作中では各人の名字が台帳と帯にあり、整理券を新設しない。予約分は通常販売へ移さない。会計は既存の方法を使う。

坂本は通常販売・電話を担当。調理、会計、スタッフ連携は利用できる。予約の捜索・照合・受渡し・厨房への取り次ぎを坂本が肩代わりしたら不合格。必要ならすぐ呼ぶ。外因が起きても条件を軽くせず、客を守るため試験を止められる。森のメモに「受取前の合図で未確認→店長へ」を準備時から置く（P15）。各約束時刻より前に救援へ切り替えられるよう森がタイマーを設定し、P20で作動を見せる。P29の表示は「残り10秒」の一か所だけ。秒まで刻んだ時刻や別の秒数は紙面へ出さない。合図前に中身と準備の見通しを確認できなければ、即座に坂本へ渡す。黒い掌＋×と「店長の取り次ぎも×」をP02・15・20・28で同じ形に反復する。

日曜の通常側の応援と責任者代行は確保済み。未決なのは12:20以後の予約担当。六件合格はアキへの引継ぎ判断の一材料となり、坂本が日曜の担当を正式に渡す。日曜の対象予約にも同じ範囲で準備し、変更・不明点は応援店長へ相談する。負けた場合は坂本の12:20出発が確定せず、再練習・別の応援を検討する。息子への約束を罰として取り上げる勝負にしない。

## P01｜単ページ｜右｜4コマ

目的：一度見た手順を奪う新人。同時に見えるページ：P02。画風：Fの手・Eの顔。

1. 初日11:45、営業説明中。坂本の両手が空の練習箱を動かす大コマ。電話を取る→名を聞く→時刻→数→厨房へ指→返答を待つ→箱→客側。八動作は途切れた小さな手の連続像、実体の腕は二本、箱は一個。顔と左胸名札まで入れる。坂本「取る。書く。渡す」。見出し「坂本 誠／青葉店・店長」、その上に太字の異名「青葉の千手」、小添え「八店の応援が頼る手」。
2. 見学の遥がノートを閉じたまま、坂本と同じ指・同じ位置へ手を動かす。直前の八動作を同じ配置で正確に再演。途中の空白で左手だけ止める。「六つ目。返事を待ちました」。見出し「青井 遥／灯台ソフト・開発」。
3. 坂本の指が止まる。「一回で盗んだのか」。遥は得意げに「八つです。三つじゃない」。坂本の太い掌と遥の細い掌を同じ形で対置。黒い四角の強者が初めて新人を見る。遥の高い二股の尾と右こめかみの白ピン二本を大きく。
4. 遥、練習箱も台帳も自分へ引き寄せる。「明日は、全部やれます」。アキの受けようとした掌が空になる。顔・白ポロ・黒腰エプロンまで描き、見出し「小川 アキ／青葉店・受取係」を置く。坂本のスマホに「日曜 決勝 13:00」の予定と息子の写真。

対向面へ：その大口で、誰の予定を引き受ける？

## P03｜単ページ｜右｜3コマ

目的：技①・八つの動作に一つだけ存在しないもの。同時に見えるページ：P04。画風：F。

1. 上半分。P01の動作図を①予約を書く→②厨房が返す→③箱が売場を通る、の三段に畳む。名前の線は台帳で止まり、箱の線は森の店頭役の手へ進む。箱の手前に太い白抜き円。遥「八つとも、名前が箱に触らない」。
2. 実景。遥が森の手の前で空箱を一手戻し、台帳の練習名を指す。遥「これ、一個を二回売れます」。坂本が練習の予約を受けた自分の手を見る。模擬の二重販売であり、実客の品には触れない。
3. 坂本「そこまで見えたか」。遥の大きな勝ち顔。「店長の手、一本いただきます」。その手で全道具を抱え、ノートを一冊落とす。森は片眉だけ上げる。「もう足りてない」。

対向面へ：観察の強さと、実際に回す強さは別だ。

技①は他人の手の抜け、技②は自分の手の詰まり、技③は物が戻る方向を発見する。三回目は単なる「アキに巻かせる」の反復にしない。決めは**完成箱が来た後で名を付ける順から、厨房へ名を先回りさせ、その名の所へ箱を出す順への反転**。一枚の帯を指示と現物表示で使い継ぎ、二つの原本を作らない。

工事音は消えないまま三件を通す。外の作業員にも必要な仕事があり、妨害者にしない。音量は離れた厨房への呼びかけを遮る表現とし、耳元の客応対まで不能にはしない。店内に危険・汚染があれば営業継続を優先しない。本筋では道路の点検・掘削で、店舗の水道や調理設備は止まっていない。

P29〜33は救援合図までの短い間を拡大する。P29のタイマーだけに秒数を表示し、時計は分単位。指示は一言、帯はまず一枚。P33で合図前に中身確認と準備の見通しが成立してから森がタイマーを止める。帯を送っただけで成功扱いにしない。

佐伯は初日12:20来店→12:26受領→12:28帰着→12:30交代、翌日12:20受領→12:22帰着。座って食べ始められる時間は二分から八分。P13〜14の母の回想、P19の「今日は座って食べた」、P40〜41の椅子と一口を残す。

蓮の八店は三十分で作った**八店別の練習用の展開試作**。実客・厨房への本番導入を済ませた描写ではない。入力→別の受取画面→一店だけの変更→帯出力までを実演し、単なる八つのアイコンで実力を済ませない。遥の現場での成功を取り消さず、再現可能な部分を広げる能力差を突き付ける。
