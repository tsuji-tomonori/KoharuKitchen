# 週刊少年誌・担当編集査読 第6回

2026-09-24。**80／100点。総合判定：通す。指定の合格基準を満たす。**

連載会議には、この三話を出せる。遥が一箱を守って役を得る。自分より早く渡す千夏を見て、喜びながら悔しがる。蓮には追いつきかけて負け、欲しかった仕事を失う。それでも翌日、去ろうとする客へ自分から手を伸ばす。仕事の改善を眺めるだけでなく、遥が何を欲しがり、次にどう食い下がるかで三週を読める。

強烈な才能に惚れて追う主人公としては、まだ弱い。第1話の準備と第2話の予行には、次のコマを先読みできる区間もある。ただ、そこで薄くなった期待を、相手からの反撃と本人の意地が取り戻している。第3話末も今回は、客の行動が変わり、遥が選んだ方法に成否が残る。前回の「接客の第一声を待つだけ」という留保は外す。全項目8点は満点に近いという意味ではない。複数の場面で機能し、週刊連載の入口を任せられる水準という判定である。

対象は [方向性](direction.md)、[全96話構成](series-structure.md)、[第1話](ch01.md)、[第2話](ch02.md)、[第3話](ch03.md)。[第1回](review-r1.md)・[第2回](review-r2.md)・[第3回](review-r3.md)・[第4回](review-r4.md)・[第5回](review-r5.md)の査読、[対応記録](revision-log.md)、[自己点検](self-review.md)も確認した。参考尺度は [物語調査 §5.2](../craft/story-research.md#52-自己評価表各観点10点満点)、演出の確認は [漫画技法 §7](../craft/manga-technique.md#7-今後ネームで使う技法チェックリスト)。項目と合格条件は今回の依頼を優先する。

## 4. 必須修正リスト〈優先度順・3項目〉

連載採否は現稿で「通す」。以下は掲載へ進むうえで直す局所であり、新たな大改稿や再査読合格を要求するものではない。点数の矢印は改善が十分に効いた場合の目標で、自動加点ではない。今回これらの原稿は編集しない。

1. **第2話P09〜10の予行を、千夏が役を取りに来る場面へ寄せる。** P09は「メモを留める→千夏へ届く→照合して空容器を渡す」を三コマ程度で通す。現P10前半の「メモなし→相談」を残りの小コマへ収め、成功例と例外を別々の頁の山にしない。P10は、千夏が遥の長い手順を二行に畳む手、それを見て口を出しかける遥、自分で包装補助へ下がる配置変更、「明日、私が使います」と正面へ置く千夏の名札へ使う。今ある人物の選択に面積を返し、後のP19で出る悔しさの種を置く。P11の昼食、P12→13の反撃、P18→19の受領と顔は位置を保つ。**ギャグと緩急8→9、主人公8→9を狙う。**

2. **第1話P44の焦点を、隠した蓮の手から、試される準備をする遥へ移す。** 第1コマの依頼票と「待ってる間も、店は開くから」は残す。第2コマは、蓮の「もちろん。同じ条件で」を画面外の声にして、遥が自作を起動する顔と手を描く。第3コマでは、椅子を正面へ寄せた遥が、自分の動く画面と相手の二端末を見比べてから顔を上げる。新しい未完成項目や説明台詞は足さず、見せたい気持ちと試される緊張を同じ反応にする。P45の全身登場、P46の試用要求は残す。顔の公開までの待ちを、主人公が自分の作品を勝負へ出す時間に変える。**ヒキ8→9、主人公8→9を狙う。**

3. **構成案の第4話P02にある本部カットを、二人の客の決着後へ移す。** P01で客から一分を得た直後は、青葉の現物の返答、運べる人と時刻、客が残るかの反応をP02〜06で連続させる。電話の途中で、蓮の試作の順次受付へ移らない。返答が来ても即受領に飛ばさず、客が時計と鞄を見て選ぶ一拍を残す。本部の未組込の説明は、この客の受領または取消が決まってから、午後の試作へ移る入口にまとめる。第3話P19の電話を取る絵は変更不要。せっかくできた話末の緊張を、翌週の二頁目で別の用件へ逃がさない。**ヒキ8→9、連載全体の起伏8→9を狙う。**

第1話の原因未確定を新たな謎解き回にすること、蓮の勝利を覆すこと、第3話末へさらに大事件を足すことは求めない。採否を変える不足は今回解消した。ここからは、既に読みたいと思った人物を待たせない修正に限る。
