# 週刊連載版の方向性

第4回改稿の設計案。全96話・11巻。原作458話は保存し、本書以下だけを連載版の正本候補とする。参照：[作品思想](../../README.md)、[調査§1〜6](../craft/story-research.md)、[ネーム技法](../craft/manga-technique.md)、[人物・固定条件](../story-bible.md)、[原作目次](../../script/README.md)、[世界観](../art/world.md)。調査の試作案より、今回のディレクター指示を優先する。

**ログライン：速く作ることに自信のある若手開発者・青井遥が、毎日正午に始まる弁当店の激戦で現場の強者と競い、ライバルと作り合いながら、自分がいなくても十二時二十分の一食を守れる仲間と仕組みを育てる十八か月。**

読者への約束は「今週も、あの手では渡せない一食を、遥たちはどう渡すか」。時計、受話器、棚から消える箱、返事を待つ指が勝負を作る。強者の手際に圧倒され、遥の小さな発見が連携へ変わる瞬間を楽しむ。作った画面の華やかさにも、袋を受け取った客の淡泊な反応にも快感を置く。食事の好みや店員の生活を勝利の小道具だけにしない。

主軸はA「現場の強者への挑戦と仲間化」。B「蓮との競作」は採用する案・確認時間・利用結果を争う継続関係。C「一食が消える謎」は各章の入口であり、犯人当てにはしない。「誰が盗んだ」ではなく「どこで約束と現物が離れた」「守れたはずなのに誰の時間が消えた」へ問いを育てる。

## 遥の駆動力

| 項目 | 初期の行動 | 成長による変化 |
| --- | --- | --- |
| want | 自分の作ったもので役立ちたい。佐伯へ自分の手で予約品を渡し、坂本と蓮に認めさせたい | 作る喜びと負けず嫌いは残す。自分の名前のない成果も欲しがれる |
| need | 相手の仕事と、任せる相手の判断を理解する必要がある | 不在でも判断できる材料と戻り道を渡す。自分への問い合わせゼロだけを目標にはしない |
| 欠点 | 答えを急ぎ、よく見せたい気持ちで確認を飛ばす。作ったものを惜しむ | 学んだことを忘れず、今度は「自分がつなげば回る」という一段深い依存にぶつかる |
| 必殺技に当たる強み | 食い違った二つを、その場の物で素早く再現する。「同じ一食」を指で追う | 第1巻：伝票・札・声。第3巻：番号と接点を仲間へ渡す。第7巻：過去の理由を現在の試験へ。第10〜11巻：次の人が選べる小さな道具へ |
| 強みの限界 | 素早い再現でも、原因の確定や全店での成功は保証しない | 他者の返答・採否・費用・客の反応を待つ。その間を埋める独断はしない |

技名を叫ぶ演出は採らない。二枚を並べる手、止まった指、相手へ札を渡す腕の反復で、読者が「遥の技が来た」と分かるようにする。第1話の一晩は残業武勇伝にせず、自宅で紙を切る短い時間と就寝を描く。

## 一時間の試合

毎話、**実際の12:00〜13:00を試合時間**として最低一場面描く。全60分を等分には描かない。準備や夜の試作は次の正午への助走。19ページの標準は、冒頭2〜3ページで今週守る人と期限、4〜8ページで策と小勝ち、9〜12ページで条件の反転、13〜17ページで選択と結果、18ページで息、19ページで次の問い。これは固定コマ割りではない。

| 型 | 正午に読者が見る勝負 | 勝敗の決め方 |
| --- | --- | --- |
| 現場戦 | 電話と列が重なる。店長の手を追う／紙の工夫を使う | 注文した本人が何をいつ受領したか。外した仕事も見せる |
| 試作戦 | 実際の昼を観察した条件を、営業外に同じ順で再現する | 確認できた条件の勝敗を残し、次の昼で見つけた不足は別の試験へ進める。客の注文へ未検証ソフトを混ぜない |
| 採用戦 | 昼に客と店員が失った時間が、午後の予算・範囲の採否を変える | 押印／保留／却下と、それで遅れる仕事を描く。資料の完成だけでは勝たない |
| 障害戦 | 12:00から複数店が同時に止まる | 既に受けた約束の照合と受渡し。画面復帰だけで終えない |
| 継承戦 | 担当者不在の昼を別の人が判断して通す | 相談先は残すが、毎回遥が駆けつける必要を減らす |

第1話は初日12:20の敗北→残りのピークの観察→営業後の照合→一晩の工作→翌日12:00〜13:00の再戦。予約の保管位置、札を動かす担当、声の返答を小さく整える。佐伯だけを列から特別に抜かさず、予約客用の通常の受渡しを守る。12:20に渡すが、坂本が販売判断を補い、他の電話は待たせ、記録の片付けも残る。**「一日だけ、坂本と二人でなら守れた」**が判定。ラストは本部の蓮と青葉の遥を通話でつなぎ、試作の一席を争う約束を交わす。視線が合った瞬間、蓮が自分の端末を退けて遥の案を求め、試される側へ反転して終える。模擬試験を山場にはしない。

## 熱さ、笑い、画面

目安は行動・対立・緊迫6、発見と感情の間3、人物の笑い1。ページを機械的に割り当てる割合ではない。笑いは毎話1ビート以上。坂本の省略、遥の見栄、蓮の軽口、森の乾いた一言から出す。客の失われた昼休み、謝罪、障害の被害確認の最中には落としのギャグを重ねない。

声の大きさを熱量と同一視しない。決めゴマは手渡し、断る手、離す指、任せた背中。小コマの連続と無音の大ゴマを対比させる。店の家具は[間取り](../art/locations.md#青葉店全体の間取り)を維持。現代日本の小さな店と普通の執務室で、技術の凄さは人の手の変化へ戻す。

ページは今回、P1右・P2左、奇数右／偶数左と明示して設計する。同時に見えるのは奇数Pと直後の偶数P。強い答えは偶数末→次の奇数頭へ。最終掲載の開始面が異なれば扉配置を調整し、全めくりを再確認する。調査資料の局所例の奇偶をそのまま転用しない。

| 守る核 | 連載版での具体化／変更 |

| 1話1ページ・1メッセージ | **原作458話の「1話1ページ」は原作・知識台本の単位として残す。連載版は別の話数で第1話46ページ、第2話25ページ、第3話以降約19ページ** |
| 問題をすぐ技術へ置き換えない | 第1話の勝ちは紙・札・返答と遥の観察。ソフト採否は後の共通条件による比較で決める |
| 悪役を作らない | 正しい反対が主人公を実際に負かす。負けた案、失った試作枠、待たせた客を次話へ残す |
| 王道の成長と対立 | A＋B＋Cを採用。昼のピークを毎話の勝負場にし、競作と仲間化を継続する |
| 勉強は物語の後 | 本編終了後の独立したおまけ2ページ。専門用語・SWEBOK対応・限界はそちら。比較ノートは短い関連索引も使う |

## 前倒しと新規創作の管理

- CON-29の蓮の実演を第1話末へ前倒し。水野の調整済み支援として本部へ招く。試作は架空注文で販売・決済なし。比較の結論は第3話へ延ばす。
- 原作REQ-02〜03の翌日以降の観察を第1話初日の残り時間・営業後に再配置。翌日の実戦は連載版の追加事件。冒頭の欠品は遥の納入事故でも同時更新バグでもない。
- 第1話の紙の方式は連載版の創作。元の欠品原因は断定せず、観察で見えた弱い箇所へ対処する。佐伯は生姜味のから揚げが好きで、自分から翌日予約する。職場の窓口当番と食事を描き、初日に削られた時間を翌日の着席へ返す。
- 森は第1話で黒鉛筆、第2話で赤ペンを使う。REQ-12の道具を前倒しした連載版内の初出。青い床テープは第5話まで出さない。一周する共通注文番号は第3巻・第27話まで完成させない。
- 第2話の代理受取は別日の条件であり、初日の欠品の真相にしない。第3話の試作比較は第2か月。6か月目より前に新注文システムを客へ公開しない。
- 新規の時刻・会話・試験条件・勝敗は作品内の創作で、SWEBOKの事例・推奨手順には帰属させない。補足は既存原作の対応節を短く参照する。

終幕の演出変更：原作ENG-01の坂本による受渡しを、連載第96話では千夏の手に移す。坂本は店内にいて別の仕事を担い、遥は客席を離れない。客が普通に受け取り、引受済みの残件を消さない核は維持する。

## 第4回改稿で固定した因果と配分

- 第1話の本文は46頁。P01右からの23組とし、全頁のコマ数・見開き・E/F案を冒頭表に固定。見開きは正午P23〜24と受領P35〜36。F案は手際・ピーク・停止・蓮の登場に限定し、謝罪・中村の退店・食事はE。画風強度の案と確定した台割を混同しない。
- 前日のトレーと仮置きP14〜15は維持。翌日P28〜31は予約棚へ向かう一箱が店頭係→電話中の坂本へ渡る別の動線。P29の呼びかけ失敗、P30の紙の角→即座の停止、P31の票・厨房の返答・販売中止と進む。二頁の溜めを削り、同じ一箱をP35〜36で遥自身が渡す。初日の欠品原因は未確定。
- 中村の退店はP32〜33、袋の準備P34、佐伯の一口P38、任命と笑顔P39。P45の蓮の全身からP46の試用要求へ。「一食」は遥のP30へ残し、接客は品名、蓮の挑戦は店数と動く物へ言葉を分ける。
- 第2話はP17の相談実演を一コマにし、P18の千夏の受領、P19の少し悔しい横顔を経て、P20で遥が予約と代理連絡の配置を試作へ写す。P11の森の取り忘れは保存。小川千夏の名札・顔・二行メモを保つ。
