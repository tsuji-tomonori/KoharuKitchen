# 仕掛けと伏線の設計

2026-09-28（2026-09-30に改訂）。[全体企画](README.md)・[話の大筋](outline.md)・[キャラクター構成](characters.md)・[対比の設計](contrast.md)と一組で読む。堆肥の比喩は、対比の軸の一つ「捨てる／寝かせる」として位置付ける。この文書は、物語に仕込む伏線・反復・小道具・演出記号をまとめた設計の正本。大筋の各章には、ここで決めた仕込みと回収を配置してある。

## 設計の方針

1. **仕込みは、その場面だけでも意味がある形にする。** 後で効くためだけの不自然なコマは作らない。子ども時代の回想は、その回の人物の気持ちを説明する場面として置き、後で別の意味を持たせる。
2. **回収は、状況を変える行動として描く。** 「あの時の○○だ」と思い出すだけで終わらせない。昔身につけた手や言葉が、今の問題を実際に動かす。
3. **失敗は捨てず、寝かせてから使う。** 物語全体を貫く比喩は「堆肥」。人物の過去の失敗や、選ばれなかった経験が、時間を置いて別の人の役に立つ。
4. **読者だけが先に気づける仕込みを、各部に一つ以上置く。** 登場人物より少し先に読者が不安になり、回収で「やっぱり」と「そう来たか」の両方を感じられるようにする。
5. **説明しない。** 伏線の意味を登場人物に解説させない。同じ物・同じ台詞・同じ構図を、違う状況で見せる。

## 1. 中心の比喩「堆肥」

### 源田の堆肥場

航は十歳の頃から、源田のみかん畑の手伝いで堆肥の切り返しをしてきた。落ちて腐ったみかん、剪定した枝、刈った草を積み、ときどき下から掘り返して空気を入れる。

> 源田「腐ったみかんも、切った枝も、捨てたらただのごみや。積んで、切り返して、寝かせたら、来年の土になる」
> 源田「湯気が出とるやろ。腐っとるんやない。育っとるんや」

この二つの台詞を、第1章の回想で航の子ども時代の思い出として置く。ドローンの墜落より前の、楽しい記憶として見せる。

### 堆肥になっていくもの

物語に出てくる大きな失敗や落選は、どれも時間を置いて、誰かの役に立つ土になる。

| 失敗・傷（積まれるもの） | 寝かせる期間 | 何の土になるか |
| --- | --- | --- |
| 航のドローンの墜落（16歳） | 7年 | 黙らずに人を呼ぶ自動操縦の設計 |
| 権藤の「操縦者の対応の遅れ」と書かれた報告 | 12年 | 機械が姿勢を、人が降りる場所を持つ「分けて持つ」操縦 |
| 氷室の月面基地の「全部緑」 | 5年 | 選抜の基準。「困ったら人を呼ぶ」機械を選ぶ目 |
| 詩織の改訂前の部品の取り付け | 8年 | 飛行ソフトウェアの版の管理 |
| ナツの腰の故障と、詩織の申告 | 2年 | 声で指示し、別の手が作業する二人の方法。火星のバルブ修理 |
| 早瀬の模擬機の墜落 | 1年半 | 「見てるか」「見てる」の確認。手でのドッキング |
| 東雲の落選 | 3年 | 予備の自動操縦と非常時の手順書 |
| 久我の落選 | 3年 | 嵐の間も震えない地球からの声 |
| 矢吹の辞退 | 3年 | 人が寝ている間も回り続ける長時間試験 |
| 航の火星での計数器の誤り | 9か月 | 再突入の修正と、次の乗組員へ渡す「堆肥帳」 |

### 航の「堆肥帳」

- 航は大学に入った年から、自分の失敗を一冊のノートに書きためている。表紙には自分の字で「堆肥帳」。何が起きたか、なぜか、次にどうするかを書く。第1章で試験室の机の上に置いてある。
- 第3章で、閉じ込められかけた権藤の件を書く。第7章の墜落の後、早瀬が「俺のも書いていい？」と言って自分の見落としを書き込む。
- 第8章以降、訓練室の壁に乗組員全員が自分の失敗を貼る掲示板ができる。船長が名前を付ける。「堆肥場」。誰の失敗かではなく、何が起きたかを書く決まりにする。
- 船にも「堆肥場」を持っていく。航行中、全員が書き足していく。
- 最終話で、航は堆肥帳の全冊を、第二次計画に乗る東雲へ渡す。

### 源田が寝かせていたノート

- 16歳の航は、墜落の後、ドローンの設計ノートを源田の堆肥場に投げ捨てた。源田は黙って拾い、乾かして、納屋にしまっておいた（第1章の回想の最後に、源田が泥のついたノートを拾う後ろ姿を一コマだけ見せる。航は見ていない）。
- 第9章、発射前夜に届く源田のみかん箱の底に、油紙で包んだそのノートが入っている。添えられた紙には一行。「寝かせてから使え」。航はみかんに気を取られ、底の包みに気づかない。読者だけが見る。
- 第10章、船内でみかんの種を植えるとき、航は包みを見つける。紙の一行を読み、開けずにしまう。
- 第15章、計数器の誤りの原因を調べる夜、航は初めて包みを開ける。16歳の自分の字で、こう書いてある。「GPSは、すぐ戻る（はず）」。7年前の墜落も、今回の停止も、同じ「はず」から始まっていた。航は初めて、自分の古い失敗を切り返す。

### 「はず」を狩る

- 16歳のノートの「（はず）」と、仕様書の「想定滞在日数は16日を超えない（はず）」を重ねる。
- 第15章以降、詩織は仕様書と手順書の中の「はず」「通常は」「想定では」に、三色ボールペンの赤で丸を付けていく。乗組員はこれを「はず狩り」と呼ぶ。
- 丸が付いた一行ごとに、「その仮定が破れたら、機械は何をするか」を書き足す。

### 船の中の畑と、火星帰りの苗

- かささぎには、食べ残しや生ごみを分解して肥料にし、小さな葉物を育てる栽培装置がある（創作上の設定）。管理はナツ。
- 第10章、航は源田のみかんの種を、船の堆肥で作った土に植える。ナツ「芽が出たら、島に持って帰んな」。
- 第11章の嵐で装置の電源が落ちかけ、ナツが自分の寝袋の保温材で苗を包む。
- 第17章、苗は小さな木になって地球へ帰る。
- エピローグで、源田はその苗を、畑でいちばん古いみかんの木の根に接ぎ木する。「新しい枝は、古い根に継ぐんや。根が覚えとることを、枝が使う」。古い仕組みに新しい機能を継ぐこと、自分の書いた物を次の人へ渡すことの比喩として、説明なしに置く。

### 演出記号「湯気」

- 過去の失敗が、今の問題を解く手がかりに変わる瞬間、その人物の手元や胸元から、薄い湯気を描く。堆肥が発酵して熱を出すときの湯気。
- 比喩が前に出すぎないよう、使うのは三回に限る。第3章（エアロックに声を付ける夜）、第15章（16歳のノートを開く）、エピローグ（接ぎ木）。
- 宇宙では湯気は立たない。だからこそ、船内で描く湯気は現実の現象ではなく心の記号だと読者に分かる。初出の第3章だけ、閉鎖居住区の実際の加湿器の湯気と重ねて導入する。

## 2. 子どもの頃にしていたことが、後で生きる

各人物に一つ以上、子ども時代に身についた手や言葉を持たせる。回想は必要な回に一場面ずつ置き、一度に全員の過去を並べない。

| 人物 | 子どもの頃にしていたこと | 最初に見せる場面 | 後で生きる場面 |
| --- | --- | --- | --- |
| 航 | 父の連絡船の航海日誌を毎日書き写した。時刻、天気、出来事、判断 | 第1章。自動操縦の記録が航海日誌の書式になっている | 第11章、嵐の48時間の記録が日誌のように読める。第15章の原因分析の時系列 |
| 航 | 父に「舵を取る前に、船に今どっち向いとるか聞け」と教わった | 第4章、選ばれた後に連絡船で | 口癖「今、こいつは何をしようとしてる？」の原点として、第5章の権限の議論で使う |
| 航 | 島の港で、父から灯りの点滅で船同士が挨拶する信号を習った | 第4章、夜の港で父と灯りを点滅させる | 第14章、つばめとの音声が落ちたとき、窓の灯りで会話する |
| 航 | 万歩計で島を何周も歩き、表示が99999の次に00000へ戻って泣いた。父「数える箱が小さかっただけや」 | 第1章。胸ポケットの古い万歩計（表示は00000）を一コマ | 第14章、計数器のあふれに気づく瞬間の回想。第15章の原因分析 |
| 航 | 源田の堆肥の切り返しと、接ぎ木の手伝い | 第1章 | 第15章、エピローグ |
| 氷室 | 山村の診療所の医者だった祖父の往診について回った。祖父は血圧計が壊れても指で脈を取り、「数字より先に、顔を見ろ」と言った。祖父の懐中時計の秒針で脈を数えるのが得意だった | 第8章、月面基地の話の前置きとして | 第16章、航は医療用の画面より先に船長の顔を見て、船長の腕時計（祖父の懐中時計を仕立て直したもの）の秒針で脈を数える |
| 権藤 | 父と河川敷で凧を揚げた。「糸は張りすぎても緩めすぎても落ちる。風と半分こや」 | 第5章、航が状態遷移の図を描く横で、権藤が紙の端に凧を描く | 第13章、着陸の最中に「風と半分こだ」。航の「分けて持つ」操縦の設計画面は、凧の糸の張りの図で表示される |
| 早瀬 | 兄とする二人協力のゲームで、いつも2P。先に走る兄に合わせるのが得意だった | 第7章、相部屋でゲームをしながら | 第14章、先を行くつばめに母船を合わせる手でのドッキング |
| ナツ | 漁師の父の船で、霧の日にエンジンの音だけで調子を聞いた。灯りの点滅で他の船と話した。もやい結び | 第8章、「音を聴け」 | 第13章、砂塵嵐の中で機材をもやい結びで固定。第14章、航と灯りの点滅で会話する。二人の子ども時代が火星で出会う |
| 詩織 | 司書の両親の図書館で、貸出カードの整理と本の修理を手伝った。「誰が、いつ、どの版を持ち出したか」 | 第7章、版の管理を持ち込む場面で | 第14章、軌道からバルブの部品の記録を即座に読み上げる。第15章、赤ペンの「はず狩り」 |
| 東雲 | 海外に住む祖父と、郵便で将棋を指した。一手が届くのに一週間。「相手の次の三手を読んでから送れ」 | 第6章、仕様書の議論の夜、東雲が一人で古い将棋盤を見ている | 第14章、二十分の遅れを先読みした非常時の手順書。第16章、往復の遅れを前提にした修正のやり取り |
| 久我 | 小学校の放送委員。台風で停電した体育館で、懐中電灯を持って全校に本を読み聞かせ、下級生を泣き止ませた | 第10章、早瀬が「こいつ、昔から声だけはいいんだ」と話す | 第11章、嵐の48時間、久我が淡々と手順を読み上げ続ける |

## 3. 繰り返す台詞

同じ言葉を、違う人・違う状況で言わせる。二度目以降に意味が変わる。

| 台詞 | 初出 | 反復・反転 |
| --- | --- | --- |
| 「少年、見学コースはあっちだ」 | 第1章、氷室→航 | 最終話。次の選抜の説明会で、袖の余った飛行服の若者に航が言いかけ、「……いや、応募者か」と言い直す |
| 「機械は、困った時に黙る」 | 第1章、源田 | 最終話、源田「こいつは、困ったらちゃんと呼ぶ」 |
| 「腐っとるんやない。育っとるんや」 | 第1章、源田 | 第15章、原因分析の報告書を前に、航が船長へ「これは腐ってるんじゃないです。育ってるんです」 |
| 「確かめている間に、船は落ちる」 | 第2章、東雲→航 | 第14章、東雲の手順書「確かめろ。お前が確かめる間は、俺の系が飛ばす」 |
| 「自分で申告して。しないなら、私がする」 | 第3章、詩織→ナツ | 第16章、詩織→船長「自分で申告してください。しないなら、私がします」 |
| 「黙るな」 | 第3章、航の堆肥帳 | 第14章、主系が止まる直前、航が画面に向かって小さく言う。機械は黙らない |
| 「少年、脈が速い」 | 第8章、氷室→航 | 第11章「お前の機械を信じろ」、第16章で反転し航→氷室「船長。脈が速いです」 |
| 「見てるか」「見てる」 | 第7章、早瀬の「次は、俺も見てる」。第10章、久我との訓練校時代の飛行前の儀式と明かす | 第14章、久我が遅れを計算して事前に送った「見てるか」が、ドッキングの瞬間に届く。早瀬「見てる」 |
| 「風と半分こや」 | 第5章、権藤の父の回想 | 第13章、着陸中の権藤 |
| 「書いてあります」 | 第2章、詩織の口癖 | 第14章「書いてあります。ナツさんが七年前に言ったことです」 |
| 「困ったら、黙らずに呼べ」 | 第9章、東雲「お前のコードが黙ったら、俺のが喋る」 | 最終話、航→東雲 |
| 「寝かせてから使え」 | 第9章、源田の添え書き | 第15章、ノートを開く。最終話、航が堆肥帳を東雲に渡すとき同じ紙を挟む |

## 6. 読者だけが先に気づく仕込み

| 部 | 仕込み | 登場人物が気づく時 |

| 第1部 | 第2章の欠陥探し試験。東雲が挙げた二十七件のうち「欠陥ではない」と採点された四件の一つが「長時間の運用で計数器があふれる」。仕様書の想定滞在日数が16日だったため不採用。航も講評で「運用上ありえない」と言う | 第14章、上昇中 |

| 第2部 | 第9章、省かれた試験の中に、矢吹が提案した「長期連続運転試験」がある | 第13章、滞在延長中に地上で実施される |

### 疑わせる先を外す

読者の不安は、第10章で飛行中に入れた「降りる場所の選び直し」の機能へ向かうように描く。新しい機能を遠く離れた船に入れる危うさを、詩織の版の確認、巻き戻しの手順と、丁寧に見せる。その機能は着陸で完璧に働く。止まるのは、何年も前から試験を重ねてきた、誰も疑っていなかった古い部品。危険は新しいものだけにあるのではなく、誰も書き直さない仮定の中にもある。

### 二十分遅れの警告

- 第13章、砂塵嵐で滞在が延びた間、地上では矢吹の班が、第9章で省かれた長期連続運転試験を始める。矢吹は家族と夕食をとりに帰り、試験は人がいない夜の間も回り続ける。
- 上昇の当日、試験が計数器のあふれを見つける。地上から「上昇を待て。主系の計数器があふれる可能性」と送信される。
- 上昇は、軌道上の母船と会える時刻の窓に縛られていて、動かせない。警告は上昇開始の三分後に船へ届く。そのとき主系はすでに自分の異常を知らせ、予備系へ手を渡していた。
- ドッキングの後、警告を読んだ航は地上へ返す。「もう、機械が言ってくれました。矢吹さんの試験も、黙りませんでしたね」。地上と船の両方で、困ったら知らせる仕組みが働いていたことを示す。誰の遅れも責めない。

## 9. SWEBOKとの結び付き

仕掛けそのものは創作だが、回収の場面は補足の入口として使う。補足では、比喩を正式な用語へつなぐ。

| 仕掛け | 補足でつなぐ考え方 | KA |
| --- | --- | --- |
| 堆肥帳・堆肥場 | 失敗の記録と、人を責めない振り返り。教訓を次の仕事で使える形に残す | ENG、MGT、PRO |
| 「はず」と「はず狩り」 | 要求や設計に隠れた仮定を書き出し、破れたときの振る舞いを決める | REQ、DES |
| 万歩計と計数器 | 数値の表現できる範囲と、あふれ | CMP、CON |
| 東雲の四件の不採用 | 前提が変わると、欠陥の判定も変わる。試験の結果は条件付きの証拠 | TST、QUA |
| 航海日誌の記録 | 運用中の記録と監視。後から読める記録が、原因分析を支える | OPS、ENG |
| 接ぎ木 | 既存の仕組みに新しい機能を加える保守と、それを他人へ引き継ぐこと | MNT |
| 凧の糸 | 人と自動化の権限の分担 | DES、REQ |
| 郵便将棋 | 遅れのある環境での運用の手順と、先を読んだ非常時の準備 | OPS、MGT |
| 貸出カード | 何が、いつ、誰によって変わったかの記録。構成の管理 | CFG |
| 二十分遅れの警告 | 長時間の試験の価値と、省いた試験の代わりに置いた運用上の規則の限界 | TST、PRC、OPS |
