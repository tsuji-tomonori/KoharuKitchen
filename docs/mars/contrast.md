# 対比の設計

2026-09-30。[全体企画](README.md)・[話の大筋](outline.md)・[キャラクター構成](characters.md)・[仕掛けと伏線の設計](devices.md)と一組で読む。この文書は、人物・場面・構成・絵・言葉に仕込む対比の正本。大筋の各章には、その章の中心の対比を「**対比**」欄として置いてある。

## 設計の方針

1. **両端を見せて、真ん中の答えを探させる。** 対比は、どちらかを悪役や不正解にするためのものではない。機械を疑いすぎるパイロットと信じすぎるパイロットを並べ、どちらでもない操縦を仲間と作る。「悪役を作らない」方針と同じ根から出す。
2. **違いだけが目に入るように、そろえて描く。** 同じ構図、同じ台詞、同じ場所、同じ時刻。変えるのは一点だけにする。
3. **一話に一つ、主な対比を置く。** 何でも対にすると、どれも弱くなる。各章の中心の対比は、大筋の「対比」欄の一行で言えるものに絞る。
4. **対比は途中で交差させる。** 両端にいた人物が物語の後半で相手の側へ一歩寄り、最後に立ち位置が入れ替わることもある。止まったままの対は作らない。
5. **教材としての対比を使う。** 同じ場面を、改善の前と後で二度描く。読者は違いを目で見てから、補足で名前を知る。

## 2. 人物の対比

人物は、互いを照らす組で設計する。各組について、何が違い、どこでぶつかり、最後にどう変わるかを決めておく。

### 航 × 東雲 — 確かめる者と、速い者

| | 航 | 東雲 |
| --- | --- | --- |
| 仕事の仕方 | 見つけた欠陥ごとに、本当かを確かめる | 誰よりも速く、多く見つける |
| 書く自動操縦 | 困ったら喋って人を呼ぶ | 燃料を一滴も無駄にしない |
| 人との距離 | 人に頼るのが下手だが、機械に人を呼ばせる | 人に聞く必要がなかった |
| 選抜の結果 | 乗る | 地上に残る |

- **ぶつかる**：第2章「確かめている間に、船は落ちる」。第6章、仕様書の「想定滞在日数」の一行。
- **交差する**：第14章、東雲の予備系が飛ばしている間に、航が確かめる。「お前が確かめる間は、俺の系が飛ばす」。速さが、確かめる時間を作る。
- **入れ替わる**：最終話、東雲が乗り、航が地上に残る。

### 権藤 × 早瀬 — 疑いすぎる手と、信じすぎる手

二人のパイロットは、人と自動化の関係でよく起きる二つの失敗の両端に置く。

| | 権藤 | 早瀬 |
| --- | --- | --- |
| 機械 | 信用しない。使うだけ | 全部任せる |
| 年齢と機会 | 44歳、最後の機会 | 29歳、初めての機会 |
| 墜落の記憶 | 機械が黙り、自分が「操縦者の遅れ」と書かれた | 機械が黙り、自分が見ていなかった |

- **同じ出来事を、操縦席の両側から**：権藤の古い事故と、第7章の早瀬の模擬の墜落は、どちらも「機械が黙った」出来事。権藤は責められた側、早瀬は見落とした側。第7章で権藤が言う「機械屋、お前の機械が黙ったんだ。早瀬、お前は見てなかった。二人とも直せ」は、十二年前の自分の報告書への答えでもある。
- **交差する**：火星では、機械を疑っていた権藤が機械と「分けて持つ」操縦で着陸し、機械を信じていた早瀬が手でドッキングを決める。二人とも、相手の側へ一歩寄ることで成功する。
- **読者に見せる一枚**：第14章のドッキングの後、つばめの扉をはさんで、機械の画面を見る権藤と、自分の手を見る早瀬を左右対称に置く。

### ナツ × 詩織 — 耳と目、声と文字

| | ナツ | 詩織 |
| --- | --- | --- |
| 分かり方 | 音を聴く。勘 | 記録を読む。版 |
| 伝え方 | 声が大きい | 書く。声が小さい |
| 動き方 | 先に手が動く | 先にペンが動く |
| 体 | 大柄、太い腕 | 小柄、細い指 |

- **ぶつかる**：第3章、隠す勘（ナツ）と記録から見抜く目（詩織）。
- **補い合う**：第8章、水中でナツの声が詩織の手を動かす。第14章、地表のナツの耳と、軌道の詩織の記録が無線でつながる。
- **入れ替わる**：第16章、詩織が指示し、ナツが従う。「ナツ、そこ押さえて」。

### 氷室 × 権藤 — 二人の指揮官

| | 氷室 | 権藤 |
| --- | --- | --- |
| 本音の隠し方 | 冗談でかわす | 仏頂面で黙る |
| 決め方 | 最後は一人で決める | 第16章、船長代理として五人で決める |

- 陽気な船長が一人で抱え込み、無愛想な副船長が合議で決める。見た目と中身を逆に置く。
- 第16章で、船長は目を覚まして、自分と違うやり方で船が進んでいたことを知る。

### 氷室 × 航 — 顔を見る者と、数字を見る者

- 船長は医者として顔と脈を見る。航は技術者として数字と記録を見る。
- 月面で、船長は顔よりも数字を信じて失敗した。航は、数字が何も言わないときに顔を見る必要を学んでいく。
- 第16章、航は医療用の画面より先に船長の顔を見て、船長の腕時計の秒針で脈を数える。脈を取る側と取られる側が入れ替わる。

### 東雲 × 久我 — 二人の落選者

| | 東雲 | 久我 |
| --- | --- | --- |
| 落選の日 | 怒りを隠さず出ていく | 笑って祝い、駐車場で一人泣く |
| 地上での仕事 | 書く。予備系と手順書 | 話す。地球からの声 |
| 乗組員への届き方 | 文字、二十分遅れの手紙 | 声、二十分遅れの交信 |

- 悔しさの表し方は正反対だが、どちらも地上で欠かせない仕事を持つ。「選ばれなかった」を一つの型で描かない。

### 矢吹 × 東雲 — 選ばれないを選んだ者と、選ばれなかった者

- 矢吹は家族を選んで自ら降りる。東雲は乗りたかったのに落ちる。
- 矢吹は、人が寝ている間も回る試験を作る。東雲は、自分がいない場所で働く手順書を残す。二人とも「自分がいなくても働く仕組み」を地上で作り、航の到達点を先に体現している。

### 源田 × 誠一 — 島の二人の年長者

| | 源田 | 誠一（航の父） |
| --- | --- | --- |
| 機械の失敗の後 | 機械を捨て、手作業に戻る | 機械に任せながら、手を離さない |
| 航への言葉 | 「機械は、困った時に黙る」 | 「船に今どっち向いとるか聞け」 |

- 航の答えは、二人の真ん中にある。機械に任せ、機械に喋らせ、人は手をそばに置く。
- エピローグで、源田は困ったら呼ぶドローンを使い始める。誠一の側へ一歩寄る。

### 御堂 × 航 — 窓を守る者と、検証を守る者

- 御堂は二十六か月に一度の発射の窓を、航は試験の十分さを守る。第9章で、二人は運用上の規則という中間の答えを作る。
- 第14章で、その規則の限界が見える。窓（上昇の時刻）は動かせず、省いた試験の警告は三分遅れて届く。どちらかが悪いのではなく、中間の答えにも限界があることを、第15章の原因分析が認める。

### 主系 × 予備系 — 機械どうしの対比

- 航の主系は喋る。東雲の予備系は燃料を節約する。表示の形も、声の調子も違う。
- 同じ仕様書から違う頭で書いたから、同じ誤りで同時に止まらない。人物の対比が、そのまま船の設計になっている。

## 3. 往路と復路の対比

同じ船、同じ乗組員、ほぼ同じ距離。行きと帰りで何が変わったかを並べて見せる。第4部の各話は、第3部の対応する場面と同じ構図から始める。

| 項目 | 往路（第3部） | 復路（第4部） |
| --- | --- | --- |
| 自動操縦を読める人 | 航一人 | 航・詩織・早瀬の三人 |
| 修正の確認 | 航が自分で確かめる | 詩織が赤を入れ、二人の署名がそろってから航が書く |
| 大事な判断 | 船長が決める（着陸班の決定） | 五人で決める（船長が倒れた後の噴射） |
| 船長と脈 | 船長が航の脈を取る | 航が船長の脈を取る |
| 詩織とナツ | ナツが指示し、詩織が記録する | 詩織が指示し、ナツが従う |
| 堆肥場の書き込み | 船長の「コーヒーをこぼした」から始まる | 全員の書き込みで埋まり、「はず狩り」の赤丸が並ぶ |
| 航の夜 | 一人で起きてコードを書く | 三人で順番に眠る |
| 窓の外 | 小さくなっていく地球 | 大きくなっていく地球 |
| みかん | 種 | 膝の高さの木 |
| 地球からの声 | 久我「良い旅を」 | 久我「おかえり」 |

## 4. 同じ場面を二度描く（改善の前と後）

教材としての対比。同じ状況を、仕組みを変える前と後で描く。読者は違いを目で見てから、話の後の補足で名前を知る。

| 章 | 一度目 | 二度目 | 補足でつなぐ考え方 | KA |
| --- | --- | --- | --- | --- |
| 第1章→第3章 | 何も知らせずに飛び続けて海へ落ちるドローン | 今の状態と次の動作を声で知らせるエアロック | 状態を利用者へ知らせる設計 | DES |
| 第2章 | 東雲の二十七件（四件は誤り） | 航の九件（全部正しい、時間切れ） | 欠陥の報告の正しさと網羅の両立 | TST、QUA |
| 第3章 | コードを直そうとして直らない航 | 夜番の手作業を手順に書いて止まらなくなる換気 | 本当の問題は要求と運用の中にある | REQ、OPS |
| 第5章 | 全員の「欲しい」がばらばらに衝突する会議 | 誰がどの状態で何を持つかを一枚にした図 | 要求の交渉とモデル化 | REQ、MOD |
| 第7章 | 表示の片隅の一文字だけが変わり、墜落する模擬 | 同じ故障、同じ操縦者で、声と表示が知らせ続けて着陸する模擬 | 人を含む試験と、状態の知らせ方 | DES、TST |
| 第7章 | 古い版の設定ファイルで合わなかった再現試験 | 版を記録した後の、結果が一致する再現試験 | 構成の管理 | CFG |
| 第5章→第15章 | 権藤の事故報告。設計の問題は脚注に一行 | 航の報告。「何がそれを許したか」を本文に書く | 人を責めない原因分析 | ENG、PRO |
| 第9章→第13章 | 締切のために省かれた長期連続運転試験 | 滞在が延びた夜、誰もいない研究室で回り続ける同じ試験 | 長時間の試験の価値と、省いた代わりの運用の限界 | TST、PRC |
| 第15章 | 航が一人で書いた修正 | 詩織が赤を入れ、早瀬が読んだ修正 | レビューと知識の共有 | QUA、MNT |

一度目と二度目は、コマ割りと構図をそろえる。変わった一点（吹き出し、表示、署名欄など）だけに読者の目が行くようにする。

## 5. 絵と音の対比

漫画は基本的に白黒。色の代わりにトーンと擬音で対比を作る。

| 対比 | 地球・訓練 | 宇宙・火星 |
| --- | --- | --- |
| トーン | 柔らかい網点、白い余白が多い | 宇宙は黒ベタ、火星は粗い砂目のトーン |
| 色（カラー頁のみ） | みかんの橙、海の青、畑の緑 | 火星の赤錆色、宇宙の黒 |
| 擬音 | 多い。波、蝉、連絡船のエンジン、ナツが聴くポンプの音 | ほとんど消す。聞こえるのは船内の機械の音と、自動操縦の声だけ |
| 重さ | 汗が落ちる。工具が床に落ちる | 汗が玉になって浮く。工具は紐でつなぐ |
| 会話の時間 | 吹き出しが隣り合う | コマの端に「送信」「到着」の時刻。吹き出しの間に余白 |
| 人物の並び | 大きな権藤と小さな航、大柄なナツと小柄な詩織を同じコマに並べ、影の大きさで対比 | 無重量では上下がなくなり、大きさの差が縮んで見える |

### 喋る機械と黙る機械の描き分け

- 自動操縦の声は、角のある専用の吹き出しで描く。形は全編で固定する。
- 機械が黙るコマは、吹き出しを置く場所に何もない空白で描く。第1章のドローン、第7章の模擬の墜落、月の「全部緑」の回想は、すべてこの空白で見せる。
- 第14章で主系が止まるとき、角のある吹き出しが画面いっぱいに並ぶ。空白のコマとの対比で、「黙らなかった」ことが絵だけで分かる。

### みかんの橙と火星の赤

- どちらも赤みのある色だが、みかんは生きている色、火星は乾いた色として描く。
- 巻頭カラーでは、第1部の扉に島のみかん畑、第3部の扉に火星の地表を同じ構図で置く。
- 最後のコマは、火星の石とみかんを同じ机の上に並べる。

## 6. 言葉の対比

| 片方 | もう片方 | 使い方 |
| --- | --- | --- |
| 「はず」 | 「確かめた」 | 16歳のノートと仕様書の「はず」。詩織の「はず狩り」で、確かめた一行と仮定の一行を分ける |
| 「全部緑」 | 「困ったら呼ぶ」 | 月面基地の表示と、船長が選抜で欲しかったもの |
| 「良い旅を」 | 「おかえり」 | どちらも久我。発射と帰還 |
| 「少年」 | 「航」 | 船長が名前を呼ぶのは一度だけ |
| 「機械屋」（見下し） | 「機械屋」（信頼） | 同じ言葉で、意味だけが逆になる |
| 「確かめている間に、船は落ちる」 | 「お前が確かめる間は、俺の系が飛ばす」 | 東雲の第2章と第14章 |
| 「見学コースはあっちだ」（氷室→航） | 「見学コースは……いや、応募者か」（航→若者） | 第1章と最終話 |
| 「選ばれないを、選びます」 | 「選ばれなかったことを、きれいな言葉で包むな」 | 矢吹と東雲 |
| 「腐っとる」 | 「育っとる」 | 源田の堆肥。捨てるか、寝かせるか |

## 7. 堆肥の比喩の位置付け

堆肥の比喩は、次の理由で「捨てる／寝かせる」「腐る／育つ」の対比の一軸として残す。

- 源田のみかん畑、捨てたノート、「はず」の一語、船の畑、接ぎ木が、第1章・第9章・第15章・エピローグの筋の仕掛けとして既に効いている。
- 失敗を「腐ったもの」と見るか「育つもの」と見るかは、人を責めない原因分析の考え方と重なる。
- 比喩が前に出すぎないよう、演出記号の「湯気」は第3章・第15章・エピローグの三回に限る。「堆肥」という言葉を人物に多用させない。
