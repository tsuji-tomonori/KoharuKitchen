# 抽出データ

元データは `.workspace/こはるキッチンの開発日誌｜SWEBOK 全458話・構成案.xlsx` です。原ファイルを変更せず、全21シートを読みます。

## 再生成

リポジトリのルートで実行します。依存パッケージはopenpyxlです。

```bash
uv run --with openpyxl python tools/extract_xlsx.py
```

別の入力・出力先も指定できます。

```bash
uv run --with openpyxl python tools/extract_xlsx.py --input /path/to/input.xlsx --output /tmp/koharu-extract
```

パスの既定値はスクリプトの場所を基準とするため、別の作業ディレクトリからも実行できます。同じ入力からは同じ内容を出力します。現在の458話構成に対して検証し、話数やID集合が合わない場合はエラーで終了します。将来、話数を変更する際はスクリプトの検証条件も更新してください。

## 統合レコードの読み方

- `話ID`・`通読順`・`部番号`・`部`・`形式`：順序と分類。形式の元データは `01`、部番号は `18` の通読順範囲から求めて `05` の部名と照合します。
- `ドラマタイトル`・`出演`・`シチュエーション`・`台本`：`17` の最新稿。台本は幕開け・前半・中盤・結末・通し台本を保持します。
- `サブタイトル`・`1メッセージ`：`01` の設計を保持します。
- `伏線・関係変化`：`19` でそのIDを仕込み／再登場として挙げた人物・伏線の行と、`13` の旧稿の関係変化を分けて保存します。全話の最新の関係変化を新たに執筆した欄ではありません。
- `SWEBOK`：KA番号・日本語名、主題、節開始頁、引用位置、原書引用頁・PDF引用頁、確認状態、`10` の一対多の項目対応、対応する `03` の行。付録にはKA名の代わりに付録ガイドという元表の分類が入ります。
- `時系列設計`・`アーク設計`：該当する `05`・`18` の全列を保持します。
- `元シート列`：`01`・`02`・`11`・`12`・`13`・`17`・`20` の各レコード。列名をそのままキーにし、`_row` にExcelの行番号を記録します。同名列もシートごとに分かれるため、旧タイトルや旧出演を上書きしません。英語原文・本教材訳等もここに保存します。

元の列を新たな共通欄へ全て平坦化すると、新旧タイトルや台本が混ざります。共通欄は執筆時に使う代表値とし、元シートの全列を別に保持する構造です。存在しない欄は創作で補完せず `null` を残します。

## シートの表現

各シートJSONの `cells` は、値または数式があるセルを `A1` 等の座標をキーに保存した辞書です。`value` は計算済み値、`formula` は元の式です。セルのリンクも存在すれば保存します。空白セルは省略し、元の行列数を保持します。値の「⏎」は `\n` に正規化します。

通常の表は5行目を見出し、6行目以降を `records` に保存します。全体設計 `00` と一話リーダー `14` は表形式ではないので、誤った列名で表にせず `cells` に全て保存します。`14` は選択中の一話の表示を保持し、458件の元データとして重複計上しません。見出しだけの `15`・`16` は `records: []` です。

書式・色・図形を複製するExcel変換ツールではありません。セルにある設計情報と値・数式を保存する抽出です。

## 数式キャッシュと検証

`data_only=True` で開いたブックのキャッシュ値を優先します。同時に元の式を別ブックから読み、キャッシュがない場合は元セルの値から参照・集計します。配列数式の本文にも対応します。未知の関数を空白で代用せず、エラーにします。

`--recalculate` を付けるとキャッシュを使わず全数式を再計算します。対応する17関数と演算子は入力で使われている範囲に限定しています。Excel一般の計算エンジンとしては使いません。

抽出時に458件、IDの一意性と7表のID集合、通読順1〜458、部の割当、台本の必須欄、前後話ID、原書対応の参照先を確認します。今回の再計算結果とキャッシュ値の照合、原案の相違、今後の確認事項は [整合性メモ](../docs/source-notes.md) にあります。
