## おまけページ

**この一食で変えたこと**  
初日の空棚 → 食い違う二枚の伝票 → 翌日の札と現物。「問題を確かめる → 一つ試す → 残った負担を見る」という順で、遥は仕事を見直しました。初日の原因はまだ確定していません。紙の方式は物語上の工夫で、返答が届かない条件や店長不在時は未確認です。一食を渡せたことだけで、どの店でも有効だとは言えません。

**作れたものと、渡ったもの**  
動く画面を作ることと、約束した一食が必要な時刻に届くことを、別々に確かめます。坂本の経験や手順は、仕事の成果を支える知識資産です。事業の目的は、アプリの完成だけでなく、客へ食事とその時間を届けることにあります。

## 制作メモ

シナリオ査読は[第1回54点](../../../docs/serial/review-r1.md) → [第2回71点](../../../docs/serial/review-r2.md) → [第3回75点](../../../docs/serial/review-r3.md) → [第4回77点](../../../docs/serial/review-r4.md) → [第5回78点](../../../docs/serial/review-r5.md) → [第6回80点](../../../docs/serial/review-r6.md)へ進みました。これは各段階のシナリオ・構成の評価で、完成画像の採点ではありません。今回、最終査読のP44指摘をネームと画像に反映しました。

画風は[第2ラウンドの選定](../../../docs/craft/art-style-round2.md)と[v2仕様](../../../docs/art/v2-style.md)に基づくEを標準にし、見せ場だけFの効果線と動きを使いました。P45は今回のディレクター指示を優先し、低い視点・斜めの前傾・集中線・周囲の息をのむ反応へ改稿しています。顔と手の紙白、黒ベタ、太細のある輪郭を基準としました。

主に使った技法は、手と小道具による動作の分割、音にかき消される用途の声、寄りと引きによる位置の確認、静かな一口と昼ピークの対照、袋・椅子の反復、見開きでの受け渡し、P44→45のめくりです。P05とP34〜36の袋、P07とP38の椅子で、同じ行為の意味が変わるようにしています。技法番号は[漫画技法の§7](../../../docs/craft/manga-technique.md)の31項目を上から数えたものです。

今回の横断検品では全44画像を順に目視し、9画像（物理10ページ）を再作画しました。生成は組み込みimage_genのみ、参照はart/v2/とround2のみ。全18稿、各画像最大3稿で、描画・加工・合成は行っていません。採用PNGは生成原本のままです。各稿の送信文は[prompts/](prompts/)、採否・五項目の全頁所見・ハッシュは[log-qa.json](log-qa.json)に記録しています。作画担当のlog-a〜fは元工程の記録として保持しました。git commitは行っていません。

## 既知の不具合

以下は今回の採用画像に残るものです。重大な因果・登場構図・識別点を優先し、軽微な揺れは記録に留めました。

- **K01／P23-24**：採用2稿目で坂本の顔と袋がノドにかかる。画面での通読は可能だが、紙の見開き用としては未解決。Fの動勢も控えめ。
- **K02／P02・P11**：通話中の受話器と台側の受話器が重複して見える。
- **K03／P10・P11・P12・P13・P17**：P22の着用前なのに遥の胸元・白帯がエプロン状に見えるコマがある。
- **K04／P20**：遥の斜め顔の白ピンが本人左側に見えるコマが残る。
- **K05／P03・P04・P05・P06・P34・P37**：佐伯の腕時計の形・装着側・省略に揺れ。P05再作画でも右腕に見える。
- **K06／P01・P02・P07・P08・P13・P14・P22・P25・P26・P30・P32・P33**：アナログ時計の短針・余分な線・指定時刻との分差が残る。P01は11:58指定に対し約11:20、P14は12:47指定に対し約12:45、P30は12:17指定に対し約12:18、P33は12:19指定に対し約12:20。P22の11:59も針が不正確。
- **K07／P07・P14・P19・P25・P26・P28・P30**：容器・電話・札置き場の形が揺れる。P05→P07で容器が黒から白へ、P19/P25で置き場が立体状、P25は確認待ち見出しが見えず、P26で電話が有線型、P28で背景二箱の置き方が変化、P30で蓋下の札が一時見えない。

- **K09／P16・P18・P22・P23-24・P28・P29**：厨房係・店頭係の顔、分け目、名札有無に揺れ。P28の中村の眉はP29以降より太い。P22の予行3コマ目で見学証が見えない。
- **K10／P33**：鍵を持つ手がコマ間で左右交替し、持ち替えが描かれない。
- **K11／P37**：佐伯の退出口が厨房口のようにも見え、南西入口への動線が曖昧。
- **K12／P34・P40・P41・P42・P43・P46**：確認前の小さな笑み、野球掲示の写真差、ペンポケット、通話吹き出しの縁、PCを出す手の左右、対置の目の高さ・分割線に軽微な差。
- **K13／P01・P07・P08・P13・P14・P31・P33・P38・P43**：床・蓋・PCに滑らかな陰影や反射が残る。
