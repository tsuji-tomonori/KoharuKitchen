# こはるキッチン v5 第1話「店長、その手を空けてください」

扉込み48頁、全46画像（単頁44枚＋見開き2枚）。ラウンド5でP43〜48の6頁を描き直し、採用画像へ更新しました。採用稿と検収結果は[ラウンド5ログ](log-r5.json)、変更理由と自己評価は[ラウンド5記録](../../../../docs/serial/v5/round-05-notes.md)を参照してください。

一目で「青葉の千手」の動きを盗んだ新人・青井遥は、翌日の予約六件を店長の代行なしで渡す勝負に挑む。名前を先に厨房へ返す工夫が、一人の昼食と店長の日曜を空ける。

上からP01→P48の順に読み、各頁のコマは上から下、各段は右から左。奇数頁が右、偶数頁が左です。通常はP01・02、P03・04のように対向します。P04は扉。P21-22（正午）とP31-32（逆転）は、それぞれ全体で一コマの一枚絵です。見開き画像を左右別々に生成・配置しません。P40の椅子からめくってP41の一口へつなぎます。

正本：[シナリオ](../../../../docs/serial/v5/ch01.md)／[方向性](../../../../docs/serial/v5/direction.md)／[人物設定](../../../../docs/serial/v5/characters.md)／[共通作画指定](style-common.txt)／[ラウンド5の対応と自己評価](../../../../docs/serial/v5/round-05-notes.md)。

各行のネームと共通指定を組み合わせて作画します。ラウンド5で使える参照画像は `art/v3/characters/`、`art/v2/backgrounds/`、`art/style-tests/round2/` と、対象頁および前後の頁の現在の画像です。大西は個人設定画が未収録のため、共通指定の8人目の文章固定を使います。
