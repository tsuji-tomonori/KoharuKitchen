# こはるキッチン v5 第10話「正論は、高くつく」

扉込み20頁のネーム（見開き1枚を含む）。作画は未着手。新キャラクター・投資審査人の百目鬼正（どうめき ただし）の登場回。

八店の受取画面の本番開発を決める審査の日。外部審査人の百目鬼は、藤堂の大案を「完成した日に古い」、遥と蓮の試作を「今日、捨てなさい」と切り捨て、最後に「このシステムを入れれば、店長は今より休めなくなる」と言い放つ。暴論に聞こえた三つの結論は、机の上の要件書・帯・相原の夜間通知だけで正論へ組み直される。

上からP01→P20の順に読み、各頁のコマは上から下、各段は右から左。奇数頁が右、偶数頁が左。P04は扉。P15-16は全体で一コマの見開き一枚絵（値札読み）です。
